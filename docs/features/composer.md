# 输入框

输入框是给 agent 写消息的地方：支持 Markdown 就地渲染、附件、`@` 引用、`/` 命令、消息排队和插话。

## 编辑区

- 占位文字为「输入消息，/ 命令，@ 引用」。
- Markdown 就地渲染：标题、加粗、斜体、删除线、行内代码、链接、列表、引用、围栏代码块；光标所在那段露出原始标记。Shift+Enter 在列表、引用里换行时自动接上标记。
- 欢迎页和会话页共用同一张卡片；点中输入框时描边混入 34% 的强调色。
- 输入框空着、没挂附件时，↑ / ↓ 翻自己说过的话（连同附件），上方一行显示「历史 n/m」，Esc 回到空框；子会话（侧边聊天、子 Agent）的输入框也一样。
- 草稿按会话、按空白页的项目分别保存在窗口内存里，切换会话不丢；没发出去的附件也按会话各存一份。
- 右键菜单：剪切、复制、粘贴、全选，按键提示按平台写成 ⌘ 或 Ctrl，不可用的项灰掉。主窗口、会话独立窗口、面板窗口里的文字框都有这个菜单。

## 工具栏

- 左边：「添加附件」、权限签、插件加的格子（截图插件的相机按钮、计划模式开关、换肤工坊的调色盘等）。
- 右边：上下文用量圆环、模型选择、思考档位、发送 / 停止。
- 输入框上方：项目切换签（28px 小签，悬停或聚焦时显示清除按钮）、Git 分支签和改动计数、工作树开关等插件格子。
- 宽度放不下时按顺序让位：先收起权限签和计划模式开关的文字，再收起上下文用量。

## 模型与思考档位

- 模型下拉支持搜索模型或供应商、按模型厂商筛选、收藏；没有可用模型时提示去添加供应商。
- 空白会话可以先选模型和思考档位，首次发送时写到会话上；新会话的思考档位默认取设置 › 常规的「默认推理强度」（默认中档），之后每个会话各自记。
- 会话进行中切换模型会先确认。还没开始输出的请求（连接中、等重试）在换模型时放弃，改用新模型重发；已经在输出的不受影响。

## 上下文用量

模型选择左边的小圆环（内置插件 `plume.status`）：

- 显示上一次请求占上下文窗口的比例，悬停写「上下文占用 41%」，到 80% 变红。
- 点开是「上下文窗口 82.4k / 200.0k（41%）」、分段进度条和各段占用：对话消息、工具、MCP 工具、技能目录、系统提示词、剩余空间；项目指令和记忆（记忆插件给的用户记忆、项目记忆）合成「记忆文件」一行，展开按文件列出路径和占用，点一个在文件面板里只读打开（工作目录外的指令文件和记忆文件也能打开）。接近上限时多一句提醒。
- 总数取最近一条完成回复的「输入 + 缓存读取 + 缓存写入 + 输出」，加上它之后进来的消息（工具结果、人的话）的估算，分母是下一轮要用的模型的窗口；各段按发请求时的内容估算（英文和代码约 3.5 个字符一个 token，中文一字约一个）再等比缩放到总数。压缩判断有多满用的是同一个数、同一份估算。压缩后到下一条回复之前仍显示压缩前的数。
- 新对话、还没有完成的回复、没有可用模型时不显示；本次启动后会话还没发过请求时不分段，整个写成「上一次请求」。
- 数字写成 812、12.3k、4.1M。

## 附件

- 可以点「添加附件」、拖入或粘贴；附件以不可分割的标记嵌在输入框里。
- 文档的文字在 agent 进程里抽取后交给模型；大图存进应用的媒体目录，发给模型前读回。
- 拖入或选择的文件，发给模型时连同它在磁盘上的路径，模型能按路径找到原文件；粘贴的截图没有路径。
- 点附件标记：会话工作目录里的文件在文件面板打开，其余在访达里显示；还没有会话的空白页也在访达里显示。
- 已发出消息气泡里的图片可以在看图器里标注，标注结果作为「标注图.png」放回这个会话的输入框。
- 撤回、分叉、编辑重发时，原消息的附件回到输入框。
- 打开失败、复制成功等结果用提示条告知。

## `@` 引用

输入 `@` 弹出补全浮层，可以引用：

- 文件和目录（项目的全部源文件夹；新建草稿只列已登记项目的目录，会话建立后按该会话的目录列）、也可以经系统文件选择器选。
- 技能（选中后插入 `/skill:名字`）、插件提供的智能体（如子智能体种类，带头像）。
- 历史会话：经 `session://` 供模型读取，随消息保存；排队、撤回、编辑重发和子会话输入框里都保留引用签。
- `@compact`：压缩当前会话。

## `/` 命令

- 输入 `/` 弹出命令菜单，命令名高亮，未写参数时以灰字提示参数格式。
- 唯一的产品内置命令是 `/clear`（开新对话）。其余来自插件：`/compact`（压缩）、`/commands`（打开命令设置页）、技能的 `/技能名`、MCP 服务的 `/mcp:<服务>:<prompt>`，装了对应插件时还有 `/plan`、`/btw`、`/review`。
- 自定义命令文件见 [Agent 扩展：命令](agent-extensions.md#自定义命令)。
- 侧边聊天等子会话的输入框只支持 `@`，不弹 `/` 菜单。

## 排队、打断与插话

- agent 正在跑时再发消息，消息排在输入框上方的队列里；这一轮以完成结束时自动发下一条，被停下时队列留着等人处理。
- 每条排队消息可以「现在就发」（打断当前这一轮，等它收尾后用这条开新一轮，发给模型时说明这是中途打断）、删除、编辑、拖动排序（手柄上按 ↑↓ 也行）。编辑会把它从队里取出，原文、附件和引用签回到输入框。
- 队列按会话保存在会话库里，重开窗口、重开应用都还在。
- 有插件往排队条加操作时（如侧边聊天的「在侧边聊天中打开」），排队条上是「更多」菜单，否则直接是「编辑」按钮。
- 侧边聊天交给主会话的任务排进同一条队，气泡标「来自侧边聊天」。
- 插话：声明了 `deliver: steer` 的命令在 agent 运行时直接插进当前这一轮，下一次请求前读到；这一轮已在收尾时排到队尾。
- 相邻的只读工具调用同时执行，会改动的单独执行。

## 引用回复内容

在回复里划选文字可以「引用」到输入框：输入框上方每段引文一枚圆角描边签，写引文首行，末尾有删除叉，悬停看全文。还有「在侧边聊天中提问」。
