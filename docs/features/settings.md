# 设置

Plume 的设置页：常规、外观、个性化、模型、智能体、存储、使用统计、关于、已归档的聊天，以及插件加的分区和项目级配置。

## 导航

设置页左边是章节列表，按组排列（插件加的分区按各自声明的组插入）：

- **基础设置**：常规、外观、个性化、模型设置，以及插件分区（浏览器、截图、代码托管等）。
- **Agent 能力**：智能体（始终在：本体的默认生图模型那一行在这一页）、命令、钩子、网页搜索。
- **数据与统计**：索引库、使用统计、存储。
- **代码与版本控制**：工作树。
- **关于与归档**：关于、已归档的聊天。

技能和 MCP 连接器不在设置里，在「插件市场」页。⌘B 开合章节列表；章节列表滑出、收起时设置内容先定在最终宽度再平移，不随动画重排。

## 常规

- **界面语言**：简体中文、English、跟随系统。只切换菜单、设置和操作提示，会话内容、代码和终端输出保持原文。主进程的文案（菜单栏图标、系统通知）也跟随。
- **权限**：默认权限、自动审核（帮我批准）、完全访问，见 [审批与权限](approvals-and-permissions.md#权限模式)。
- **常规**一节：
  - 默认文件打开目标：点文件路径时用哪个应用打开，列出本机已装的 macOS / Windows 编辑器等，没设过时是 Zed。
  - 默认推理强度：新会话的思考档位（默认中档），每个会话可以在输入框右侧单独调整。
  - 显示思考过程：在对话里显示模型的推理，点开看全文；关闭时只在底部看到它正在思考。
  - 智能标题总结（默认开，由 `plume.title` 提供，见 [Agent 核心](agent-core.md#智能标题)）。
  - 归档后收起项目。
  - 运行期间不让电脑休眠。
  - 平台：当前运行环境。
- **请求重试**：见下文。
- 页头列出各项目的配置路径、覆盖值、被拒绝的项和错误。
- 默认推理强度和重试策略存在 `~/.plume/settings.json`；默认文件打开目标、显示思考、归档后收起存在窗口本地；不让休眠由主进程记在 `keep-awake.json`。

### 请求重试

- 网络中断（连接失败、超时、传输中断）和服务端故障（限流、服务过载、暂时不可用）分别设置：重试次数（含无限重试、不重试）、间隔方式（固定间隔或逐次递增）、初始间隔。次数不含首次请求。
- 「固定间隔」实际在设定值上下浮动两成；服务端要求等待时最多等 5 分钟。
- 改动立即生效，正在重试的请求从下一次等待起用新值；已执行的工具不会重做；点停止可立即取消等待。

## 项目配置

- 当前工作目录的 `.plume/config.json` 覆盖全局设置：对象深合并，数组和标量整体替换，再经同一套校验；只读工作目录这一处，不向上找。
- 可覆盖：默认模型、默认思考档位、权限模式、允许名单、个性化、重试策略、默认生图模型（按会话所在项目解析）。会话里显式选的模型优先。
- 不接受 `providers`、`apiKey`、`credentials`、`githubToken`、`mcpServers` 和 `magpie`；`hooks` 不合入设置（由钩子插件单独读取，且需信任）。
- 配置无效时使用全局设置并提示文件位置，不回显文件原文。

## 模型设置

- **供应商**：名称、API 格式（Responses、Messages、Chat Completions 等）、连接地址、API key；可重命名、启用 / 停用、删除（连同它下面的模型）、测试连接。
- **模型**：从当前地址「拉取模型」或手动添加；模型编辑器包括模型 ID、显示名称、上下文窗口、最大输出、输入 / 输出 / 缓存命中 / 缓存写入价格、是否支持思考（及可选的推理档位）、图片输入、工具调用、「生图模型」开关。从模型目录选中时自动填好能力和价格（含长上下文分档价）。可多选批量删除，删除当前默认模型时提示另选。
- 每行行尾有「测试此模型」按钮，旁边的行菜单里是设为默认模型、编辑、删除（Magpie 的模型只能设默认）。生图模型不进对话的模型下拉、不能设为默认对话模型，「设为默认」变成设为默认生图模型，「测试」画一张小红点图（会计费）。
- **模型目录**：上下文、能力、价格的参考数据缓存在 `~/.plume/model-catalog.json`，每小时同步一次，页面显示来源、更新时间、模型数，可「立即更新」。
- **导入 / 导出**：供应商配置导出为文件（带 key，权限只给本人），可再导入；结果用提示条告知。
- **key 的保管**：key 不进界面进程，输入框只提示「已保存」，填新的才替换。key 用 AES-256-GCM 加密存在数据目录的 `credentials.json`，钥匙是同目录的 `vault.key`（都是 0600），`settings.json` 里不写 key；手写进 `settings.json` 的 key 照样能用，下次保存时挪走；删掉供应商时一起删。钥匙读不出来时报错，不换新钥匙。
- 每次保存都校验，地址等没写完时存不进去，编辑器上显示原因。
- 会话选了模型且可用就用它，否则用默认模型；默认模型失效时落到第一个可用的。

### Magpie

Magpie 可以接管 Plume 的模型和资源：

- Magpie 写入的网关作为一个只读的「Magpie」供应商排在最后：能测试、设默认，不能改、删，不参与导入导出；改了下一轮就生效，界面的模型列表需重启刷新。
- Magpie 资源库分发的技能写进 `~/.plume/skills`，全局指令由系统提示词插件读取并与设置里的全局指令合成一段，MCP 服务在连接器页标「由 Magpie 管理」：名称、开关、启动方式、变量和删除都锁住，连接状态、工具列表、重连和 OAuth 登录照常；和自己的服务重名时保留自己的；改了要重启 Plume。

## 个性化

- **全局指令**：对所有会话生效的指令（说明里提到项目级的 PLUME.md / AGENTS.md / CLAUDE.md）。
- **语气风格**：亲和温和（默认）、专业严谨、极度精炼、直接坦率、幽默风趣。
- 装了记忆插件时，两者之间多一节「记忆」，见 [Agent 扩展：记忆](agent-extensions.md#记忆)。
- 存在 `~/.plume/settings.json` 的 `personalization`。

子智能体的定义和模型选择，以及「会话」一组里各后台功能的模型选择、默认生图模型，见 [多会话协作：设置 › 智能体](multi-session.md#设置--智能体)。

## 存储

- 显示会话记录（`~/.plume/sessions/sessions.db`）的大小和条数。
- 导出：把所有会话另存为一个 SQLite 文件。
- 清除会话记录：选一段日子，按会话最后活动时间算，删除那段的会话。条数、按天的大小和删除都以顶层会话为单位，子会话（侧边聊天、子 Agent）的大小算在它头上、跟着它删。正在运行的会话不删。
- 删除会话不清理图片等媒体文件（媒体按内容命名，可能被多个会话共用）；使用统计不受影响。
- 单个会话的导出在会话菜单里，见 [会话与侧栏](sessions-and-sidebar.md#会话右键菜单)。

## 使用统计

插件 `plume.usage`（从插件市场安装），装上后在「数据与统计」组、存储上面；停用后这一页撤下，花销照记。数据只在本机。

- **工具条**：区间（今天、7 天、30 天、全部、自定义）、供应商筛选、按模型或供应商搜索、自动刷新（5 秒、30 秒、每分钟）、手动刷新、导出 CSV。
- **五格指标**：Token（输入、输出、缓存写入，不含缓存读取）、请求数和平均每次 token、费用（按调用时记下的价格；有请求查不到价时写「≥」）、缓存命中率、输出速度（总输出 token ÷ 总生成时间）和首字时间。
- **柱状图**：今天按小时、其余按天；看 Token、费用、请求数或速度，按模型、模型 · 供应商或供应商堆叠；右边是各系列数字和占比，点一下从图上拿掉；前八名以外并成「其他」。
- **Token 构成**：计费 token 按来源分十类的环图（系统提示词、项目说明与记忆、技能与智能体、工具定义、用户消息、注入内容、助手消息、工具结果、输出的思考和回复），下面一行是输入里缓存读取、写入、未缓存的占比。各类的比例按发出去的内容估（和上下文用量、压缩同一份估算：英文和代码约 3.5 个字符一个 token，中文一字约一个），再按账单上的实数分下去。
- **耗时构成**：等待首字、模型思考、模型回复、工具执行四段环图，右上角是会话数（含已归档几个）、轮次和工具调用次数。
- **缓存未命中**：本该命中缓存却按全价重算的输入量、占比、按当时价格多花多少，按原因分行；相邻两次请求比对，压缩、撤回之后、换模型的单独列出；重开应用后第一次请求记「原因不明」。
- **热力图**：最近 53 周每天的用量，跟随供应商和搜索筛选，不受区间限制。
- 回复、压缩摘要、插件发起的调用都计入花销；Token 构成、耗时构成、缓存未命中只算会话里一步步发的请求（含子智能体）。删掉的会话不计会话数，但它的 token 和计时仍在；删掉的供应商只显示 id。

## 数据目录

- 数据目录是 `~/.plume`；设置 `PLUME_HOME` 后改到那里，Electron 的浏览器数据也跟着放进其中的 `chromium/`。
- 主要内容：`settings.json`（模型和 agent 设置，0600）、`credentials.json` 和 `vault.key`、`sessions/`（会话库，含排队消息）、`session-media/`（图片等媒体及缩略图）、`scratch/<会话 id>/`（会话临时目录，随会话删除）、`projects.json`、`plugins/`（市场装的插件）、`local-plugins/`（本地上传的插件）、`market.json`、`plugins.json`（停用名单）、`plugin-data/<插件名>/`（插件私有数据）、`appearance.json`、`locale.json`、`keep-awake.json`、`window.json`、`backgrounds/`、`model-catalog.json`、`bin/plume-plugin`。
- 开发版（`pnpm dev`，没打包）和装好的应用共用这个目录，会话、设置和插件都是同一份。
