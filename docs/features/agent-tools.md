# Agent 工具

agent 可以调用的基础工具：文件读写、资源地址、命令与后台任务、定时唤醒、网页搜索，以及市场插件提供的语言服务和符号索引。

## 文件工具

内置插件 `plume.tools` 提供 read、write、edit、ls、glob、grep：

- 改文件前需要先读过（读过哪些文件只记在内存里，重开应用后改文件前要重读）；写、改按权限模式审批。
- 不写数据目录 `~/.plume`（会话临时目录除外，读写临时目录不问人）；`~/.plume/settings.json` 等视作密钥文件。
- read 读 PNG、JPEG、GIF、WebP 图片时把图交给模型（最大 5 MB，不缩放）；BMP 人看得到，发给模型时换成一句「不支持的图片」。
- 项目的额外源文件夹可以读取；人拖进来的附件文件即使在工作区外也允许读取（不允许写）。
- grep 使用随应用附带的 ripgrep（`PLUME_RIPGREP` 或 PATH 里的 `rg`），都没有时用内置兜底实现。
- edit / write 在实际写入时记下修改前后快照，供文件交付卡汇总和撤销（见 [文件面板与文件交付](files.md#文件交付卡)）。
- 装了语言服务插件时，edit / write 后附上该文件的错误（见下文）。

## 资源地址

read、ls 除了文件路径，还认 `scheme://路径`（末尾可加 `:10-40` 只取几行，只写 `scheme://` 列出内容）。地址清单写进系统提示词。

- `scratch://`：会话临时目录，唯一可写的地址，write、edit 都认；会话删除时一起删。
- `artifact://<id>`：压缩时剪掉的大块原文，按会话存在内存里（最多 30 份），子会话读不到父会话的。
- `session://<id>`：另一个会话的转录（一条消息一行，工具调用只留名字）；`session://` 列出最近的会话（不含当前、归档和子会话）。
- `plugin://<插件名>`：插件的 README（没有就给版本和说明），`plugin://<插件名>/<路径>` 读插件目录里的文件。
- `skill://`：技能正文和目录（技能插件提供）。
- `mcp://`：MCP 服务声明的资源（MCP 插件提供）。
- `agent://<id>`：子智能体交回的结果（子智能体插件提供）。
- 非本项目内容由 read 包进 `<resource origin="…">`，模型据此区分来源。软链会二次校验，越界拒绝。

## bash 与后台任务

- 命令经沙箱运行（见 [审批与权限](approvals-and-permissions.md#命令沙箱与提权)）。没给时限的命令超过 120 秒自动转成后台任务；无歧义的 `cat`、`ls`、`rg` 当场改用 read、ls、grep。
- 完整输出写进会话临时目录的 `tool-output/<uuid>.log`（权限 0600）；给模型的部分截断时，结果末尾给出日志路径，截断标记的行号就是日志行号，可以用 read 按偏移读省略的部分。
- 后台任务：`run_in_background` 起的、超时转后台的、命令退出后留下的进程都算这个会话的后台任务；`bash_output` 读输出或停止。删除会话、退出应用时停掉。
- 顶层会话里后台任务自己结束时，退出状态和未读输出自动送给模型（对话里一行「后台命令完成」）：闲着就开一轮，忙着在步骤之间读到；模型已读过或已停掉的不送。人按停之后，之前起的任务继续跑，但不再叫醒会话。子会话里需要模型自己用 `bash_output` 读。
- `monitor`：跑命令并把新输出分批送给模型——第一行后等 1 秒凑批、两批至少隔 10 秒、每批留最新 4000 字、单行截到 1000 字，去掉颜色和 `\r` 重画；满 100 行（最多 1000）或 10 分钟无输出（最多 1 小时）自动停止；人按停时跟着停。子会话不提供。
- 命令前后在 git 仓库里比对改了哪些文本文件（最多 200 个文件、单文件 2 MiB、合计 16 MiB），记作命令改动供交付卡展示；命令改动不能自动撤销。二进制、超限、密钥文件只留警告。
- Windows 上 PowerShell 的退出码按 PowerShell 规则读，停命令用 `taskkill /T /F`。
- 后台任务的列表、输出和停止在任务面板里（见 [运行诊断](diagnostics.md)）。

## 定时唤醒

`plume.tools` 给顶层会话提供 `schedule_wakeup`、`cron_create`、`cron_list`、`cron_delete`：

- 到点时作为一条送达叫醒会话，对话里一行「定时唤醒」。
- 环境卡片里列出待触发的唤醒，可以取消；环境开关收着时，开关上的圆点和说明里数待触发的唤醒和在跑的监视。
- 唤醒只在本次运行中有效。按停全部取消，并提示「已停止，N 个定时唤醒一并取消。」；撤回、编辑重发只取消被截掉那几轮里建的。

## 网页搜索

内置插件 `plume.web`：

- `web_search`：按一句查询搜网页，最多 8 条结果（标题、网址、摘要，部分服务附总结），30 秒超时。
- `web_fetch`：把 http(s) 网址读成文字（保留标题、列表、表格、代码块；也读纯文本、JSON、XML）。单个响应最多 2 MB，正文太长时截断，完整内容存进会话临时目录并给路径；最多跟 3 次同站跳转，跨站不跟。解析不了、非 http(s)、带账号密码的地址直接拒绝。
- 两个工具只读，不弹审批，用通用工具卡片；搜到的内容按不可信内容交给模型。
- 设置 › 网页搜索（「Agent 能力」组）：选一家服务、填 API key（申请链接在系统浏览器打开）。支持 Tavily、DeepSeek、Brave Search、Exa（需 key），DuckDuckGo 速答、DuckDuckGo 网页（无需 key）。没选时自动挑：只有一家能用就用它；只有一家填了 key 就用它；都没填用 DuckDuckGo 速答；填了多把又没选时报错提醒去选。再点一次已选的那家即取消选择。
- key 停手后自动保存，框里显示「已保存」，填新的替换，「清除」删除；设置存在插件数据目录的 `search.json`（0600），key 不发给界面。改了下一次搜索就生效。

## 语言服务（LSP）

插件 `plume.lsp`（从插件市场安装）：

- `lsp` 工具四种操作：`references`（全部引用，含别名导入和重导出链）、`definition`、`diagnostics`（单个文件的类型错误）、`rename`（只列出需要改的地方，由 agent 用 edit 逐个改）。
- edit、write 之后，把语言服务器在该文件里报的错误附在结果后面：只附错误、最多 10 条、最多等 2 秒，没有错误就不加。
- 语言：TypeScript / JavaScript（随插件附带 tsserver）、Python（basedpyright / pyright）、Go（gopls）、Rust（rust-analyzer）、C / C++（clangd）；后几种用本机 PATH（登录 shell 环境）上的，装上后下一次提问即可用。
- 找不到服务器时 `references` 退回同语言文件的文本搜索并说明；`rename` 没有服务器时拒绝。
- 服务器第一次被问时才启动，启动慢时这一次先给文本搜索结果；空闲十分钟停掉。同一目录的会话和子会话共用一套，最后一个使用它的会话结束（删除、归档、换项目、子会话跑完一段）时停掉。
- 读取权限与 read 一致：项目额外源文件夹可读，项目外和密钥文件按同一规则审批。
- 转录里写「查符号 parseConfig」。

## 符号索引

插件 `plume.index`（从插件市场安装）：

- `symbol` 工具：查函数、类、接口、类型或常量定义在哪个文件哪一行，最像的排在前面。
- 第一次在项目里用时建索引；存下的索引新会话只信 10 分钟。
- 收录 TypeScript / JavaScript、Python、Go、Rust、Java、Kotlin、Swift、Ruby、PHP、C / C++、C#、Scala、Shell、SQL、Vue、Svelte；在 git 仓库里只收 git 认为该看的文件，跳过 `node_modules`、`dist`、`vendor` 等目录、超过 800KB 的文件和二进制；最多 40000 个符号，到上限时告诉 agent。定义靠正则识别，认不出时 agent 改用 grep。
- 设置 › 索引库（「数据与统计」组）：选项目看符号数、已索引文件、索引大小和上次构建时间；「建立索引」「重建」；「试搜」（至少两个字符，点一条用默认应用打开）。
- 转录里写「查找符号 runAgent」，并入读文件那段活。
