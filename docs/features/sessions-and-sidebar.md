# 会话与侧栏

侧栏是 Plume 主窗口左边的会话列表和全局入口：在这里找会话、管理项目、进入插件页面和设置。

## 侧栏顶部

- 搜索按钮打开命令面板：列出最近的会话（按更新时间排，副标题是所属项目），按组匹配，键盘上下选择、回车执行。组里有：新对话、置顶 / 取消置顶当前会话、归档当前会话；去处（插件加的页面、「插件市场」、设置、开合侧栏 ⌘B）；面板区里能开的面板；主题（浅色、深色、跟随系统，皮肤接管配色时不列）；项目；设置的各个分区。
- 通知铃打开通知菜单：等批准的排最前，其次是失败、完成，点一行进入那个会话。插件页面上需要注意的事（如定时任务失败、SSH 运维助手等批准）也列在这里。
- 去处：插件经页面接口加的页面（拉取请求、定时任务、画廊、SSH 主机等）排在「插件市场」前面，有需要注意的事时那一行挂数目。
- ⌘B（Windows 上 Ctrl+B）开合侧栏；在设置页里开合的是章节列表。开合动画 340ms，外层宽度收缩、内容被裁切；窄窗口下侧栏是盖在正文上的抽屉，Esc 收起。
- 后退、前进：macOS 上 ⌘[ / ⌘]，Windows 上 Alt+← / Alt+→，鼠标侧键也可以；光标在输入框里时这些键归输入框。

## 会话列表

- 分三段：置顶、项目、聊天（不属于项目的会话）。项目名和「聊天」标题在滚动时吸顶，列表两头不渐隐。
- 「项目」标题上的列表设置菜单：项目里的会话按最近创建（默认）、最近更新或手动顺序排；聊天和置顶按最后活动排；可以收起或展开全部项目。
- 项目可以拖动排序；会话只能在所属项目内拖动，拖过之后只有该项目切为手动排序，别的项目照旧，新会话排在手动顺序最前；在列表设置里另选排法时，拖过的项目也跟着改。顺序会保存。
- 从一个会话开出的后续会话（分叉出来的、建议新会话开出来的、计划交给新会话执行的）在来源同组时嵌套在来源下面，统一缩进一层，可以折叠、显示计数，切进去时自动展开；来源被置顶、归档、移动或删除后，各自按自己的分组独立显示。
- 没发过消息的会话不列。没有任何项目时仍保留「项目」标题，悬停或键盘聚焦时露出新建按钮。
- 悬停卡：项目卡显示会话数和全部源文件夹路径；会话卡按需显示轮数、步数、用量、费用和缓存命中率，用量里主会话一格、子会话按建它的插件各一格（名字取插件的显示名）。打开菜单时悬停卡收起。
- 会话行上有置顶、归档两个悬停按钮；有独立工作树的会话空闲时行首显示 ⑂，悬停说出分支。

### 状态点

行首的状态点区分：在跑（子会话在跑时父会话也算）、等批准（警示色实心点，子会话在等也标在父会话上）、完成、失败（人没看着时跑完或出错的）、手动未读、空闲。完成、失败、等批准只记在当前窗口内存里；选中会话即清除未读。

### 会话右键菜单

置顶、重命名、归档、标为未读、移到项目、在访达中显示、复制工作目录、导出为 SQLite、导出为 Markdown、复制会话 ID、「打开方式 › 新窗口」，以及插件加的项（如「查看调用轨迹」）。

- 重命名后会话标记为人工标题，智能标题不再覆盖；重命名失败时保留表单内容。
- 置顶和未读存在会话摘要里；归档保留置顶状态。
- 移入项目会切换工作目录，移出项目保留原目录；主会话或它的子会话正在运行时拒绝移动。
- SQLite 导出只复制这个会话及其草稿、费用；Markdown 导出保留正文、工具摘要、子智能体结论、后台送达（每份一行标题，下面引出送给 agent 的原文）和附件名称，不导出思考和普通工具输出；插件工具的摘要由插件给，没给时只写工具名。导出失败时保留原文件，成功后提示条上有「在访达中显示」。

## 项目

- 一个项目可以添加多个源文件夹，并可切换主文件夹。主文件夹用于新会话和 Git；已有会话的目录不变。额外源文件夹可以读取，写入审批和工作树隔离边界不因此扩大。文件树按源文件夹分组。
- 项目菜单：新建会话、编辑、在访达中显示、归档聊天（带数目）、移除。移除项目先归档它的聊天，再取消登记。
- 设置 › 常规的「归档后收起项目」打开时，项目下的会话全部归档后项目一起从列表收起；从没有会话的项目始终保留。
- 新对话直接打开当前项目的欢迎页，首次发送才创建会话；输入框上方可以切换项目或回到不属于项目的聊天。

## 新会话欢迎页

- 单列布局：左上是按本机时间的问候（夜深了、早上好、上午好、中午好、下午好、晚上好），随界面字号变化；问候下面一行默认问「要在某个项目里开发什么？」，不在项目里时是「想聊点什么？」，都和输入框左边对齐；输入框下面靠左排着四个建议按钮。
- 问候下面那一行插件可以换掉（`ui.welcomeLine`，比如市场插件「每日一句」）：有插件时那一行先空着、等它答复，回来了在原地淡入，输入框不跟着移动；它没给、出错时显示默认的那句。
- 半身像插图趴在输入框右上沿，只露出肩膀以上，窄窗口缩小一档；深色主题下沿边缘补一圈淡亮边。
- 插图从输入框上沿往上冒出、那一行淡入（340ms）；建议按钮以 65ms 间隔、260ms 时长依次展开；首次发送后输入框从下方 16px 升起并淡入（220ms）。打开已有会话不播放；开启「减少动态效果」时直接到位。

## 会话标题栏

- 显示图标、标题和菜单按钮，菜单向下弹出，内容与侧栏的会话右键菜单相同（含插件加的项）；长标题让位给右侧按钮。切换会话时旧菜单关闭。
- 标题栏右侧有插件加的会话工具栏按钮（如「环境」开关）和面板区开关。

## 归档

- 侧栏行上的归档按钮、右键菜单、命令面板都能归档。归档不会停止正在跑的那一轮。
- 设置 › 已归档的聊天列出全部归档会话，不属于项目的归在「聊天」一组；可按项目筛选、搜索。每行日期后面写消息条数，可以打开、取消归档或删除；也可以一次删除全部归档会话（永久删除，使用统计里的数不受影响）。
- 删除确认框写明消息条数、从它开出的后续会话会留下，第二个按钮可以连后续会话一起删；会话有独立工作树时，确认框里还会写明会留下什么（未提交的文件在哪、未合并的提交在哪个分支）。

## 会话存储

- 全部会话存在数据目录的 `sessions/sessions.db`（SQLite）。消息只追加；模型回复在流式输出时边收边写，应用意外退出后，已收到的部分作为一条被中断的回复保留，转录末尾给出「继续」。
- 撤回、编辑重发会真正删除截点之后的记录；分叉把前面的消息拷进新会话。每次计费调用另记一笔花销，删会话不影响统计。
- 会话库打不开或结构版本不符时，Plume 启动失败并弹窗说明库路径和原因，点掉后退出，库文件不被改动。
