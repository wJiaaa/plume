# 对话与回复渲染

对话区（转录）显示人和 agent 的往来：回复正文、思考、工具调用、各种状态行，以及编辑、撤回、分叉等操作。

## 转录的组织

- 连续的读、搜索、跑命令、改文件、网页、MCP 调用等合并成「一段活」，按类归组；跑完的一轮不自动收起。
- 插件登记了专用卡片的工具（生图、子 Agent 派发、网页预览等）单独一行，用插件的卡片画；插件可以逐次判断，只画一行的那几次（网页预览的截图检查）照常并进一段活。
- 思考行、运行行（思考球，刚跑完的工具留 2 秒）、工具行（耗时、结果里的图、命令和 JSON 着色、带路径和行号的 diff）。
- 回答底下有时间、复制、耗时和输出速度（tok/s）。
- 换模型时插入分隔线；读不出的记录换成一行说明；按时间插入分隔；长对话有问题导航。
- 长的用户气泡折叠显示；对话贴底时跟随新内容滚动，往上翻后不会被拽回底部。
- 紧挨着查看同一个后台任务的几次输出合成一行「查看「说明」的输出（N 次）」。
- 只带后台命令结果的送达挂在正在做的那段活上（失败时标题行挂失败记号）；挨着的几条合成「N 个后台命令结束」。
- 压缩在转录里是单独的压缩行，见 [Agent 核心](agent-core.md#上下文压缩)。

## 状态行

- 后台送达：「后台命令完成」「监视到 N 行新输出」，悬停看命令，点击定位到任务面板里的输出。
- 「定时唤醒」：agent 设的唤醒到点。
- 「来自 X」「X 的答复」：别的会话发来的消息，点开读全文，箭头跳到对方（会话互通插件）。
- 「来自新会话」：建议新会话或审阅会话交回的结果，点了过去。
- 交回结果的插件没画自己那一行（没登记、停用了）时，画成一行标题，失败、只做了一部分写在右边。
- 「消息来自 @agent」：子智能体交回的结果，带头像，几份一起到时叠放头像；出错时红字。
- 交出去的会话：从这个会话开出、还在进行的会话在输入框上方有一行进度，点了过去，看过就收起。

## 请求重试的显示

- 连接失败、超时、限流、服务过载等需要重试时，转录里一行「正在重试 / 已恢复」，可以展开看原始错误。
- 放弃时给出下一步：「去设置」或「继续」（发一句继续）。
- 重试策略在设置 › 常规的「请求重试」，见 [设置](settings.md#请求重试)。

## 停下以后接着做

- 一轮结束的原因（完成、停止、出错、用满步数、原地打转、退出应用时被中断）记在会话上，转录末尾据此给出入口，如「已暂停 · 继续」；「继续」发的话不画成人的气泡。
- 一轮正常结束但最新的待办清单还有没勾的项时，写「计划还有 N 项未完成」。
- 「重试」：确认后把最近一条人发的消息原样重新发出（连同会话引用）。请求被放弃时不出现「重试」。
- 被停下的工具调用在通用工具卡片上标「已停止」。
- 后台子 Agent 还没回来、结果还没送进会话、后台命令还在跑或定时唤醒还没到点时，不显示「继续」。

## 编辑、撤回、分叉

- 只有最后一条用户消息能编辑；运行中按钮置灰；操作前确认。屏幕上的结果等后台事件确认后才更新。
- 撤回：删掉这条消息及之后的内容，草稿连同附件放回输入框。
- 编辑重发：改完从这一条重新发。
- 分叉：从某条回复开出一个新会话，复制前面的消息，分叉按钮防连点；新会话嵌套在来源会话下。
- 撤回和编辑会停掉这个会话全部的后台派发（子 Agent、侧边聊天交来的任务），截掉那段里起的后台命令、监视和唤醒不再送达。
- 连文件一起退回：截掉的那几轮改过文件时，确认框列出这些文件，可选「连文件一起撤回」。全有或全无：有文件来自命令、中途或之后被改过、在项目外、或改动没记全时，一个都不写，对话也不截，原因报给人；新建的文件会被删掉。退回后刷新改动统计和 Git 面板。
- 侧边聊天只能编辑重问最后一句，不涉及文件退回；子 Agent 的过程里没有这三种操作。

## 回复正文（Markdown）

- 平滑出字、淡入，表格、代码块高亮、KaTeX 公式、Mermaid 图。
- 代码高亮配色跟随外观页选的浅色 / 深色代码主题，代码字体、字号、行高、字距实时生效。
- 图片：助手回复里的本地图片、流式占位、文档相对路径和 HTTPS 图片直接显示；回复里的远程图片引用不自动加载，保留为链接。缺失、越界或加载失败的仍显示为链接。远程图片经主进程加载，不带 Cookie，HTTPS 重定向逐跳校验。
- 网址：点击在系统浏览器打开（装了内置浏览器并设为默认时开在内置浏览器，Shift 点仍交给系统浏览器）；右键菜单是「在 <默认浏览器> 中打开」（查不到名字时写「在系统浏览器中打开」）、插件提供的打开方式、「复制链接」。

### 文件签

- 链接和行内代码里的路径、`file://` 地址，带 `:42` 或 `#L42` 行号的，画成文件签；对话里 read / edit / write 过的当场画，其余在会话工作目录里查找（git 仓库里按 git 认的文件找，问 git 时不执行仓库配置里的程序），同名多个时给候选让人挑。
- 点击在文件面板打开并定位到那一行。悬停出口条：「用默认应用打开」「在访达中显示」，插件可加按钮（如内置浏览器打开 `.html`）。
- 右键菜单：打开、在所选编辑器中打开（设置 › 常规的默认文件打开目标）、「打开方式 ▸」、在访达中显示、复制路径、复制相对路径；复制成功弹提示条。
- 只在对话里画；文件面板里的文档照常显示文字。复制回复时不多出换行。

### 在终端运行

shell 代码块（bash、sh、zsh、shell、console、terminal）标题栏上有 ▶：去掉提示符和注释行后交给终端插件，在该会话已有的终端里执行（没有就新开），shell 准备好后带回车执行；没装终端插件时提示安装。只在有会话的对话里出现。

### 原生界面块

回复里的 ```` ```ui ```` 围栏由插件 `plume.native-ui` 画成卡片、表格、图表和表单：

- 组件：布局（Card、Stack、Row、Grid、Tabs/Tab、Each、Divider）、文字与读数（Text、Heading、Stat、Badge、Callout、Progress）、表格、图表（柱、折线、面积、环形饼图）、输入（Input、Select、Choice、Toggle、Slider）、按钮。
- 只允许白名单表达式，不执行任意 HTML、样式或脚本。模型通过 `ui_help` 工具获取完整语法。
- 流式阶段显示点阵占位和扫光，完整后自上而下揭开；整段完成后才能操作。
- 按钮 `send` 把一句话连同全部字段值（`<interface-values>…</interface-values>`）发到所属会话，按钮下方逐字显示将发送的内容；发送期间锁定，成功后显示回执。
- 声明有错时整块退回源码，并在下一条用户消息的请求副本里附上诊断（最多 8 条）。
- 每个块的表单值、页签、最后一次发送回执按会话保存在本机，最多最近 200 个块。复制回复时输出可读文字，表格和图表转为 Markdown 表格。
- 上限：Each 200 项、整块 4000 节点、表格 500 行 30 列、图表 500 点 6 系列，超限退回源码，不截断。
- 未安装或停用时显示源码。

### 下一步建议

插件 `plume.followups`：模型在一轮最后的回复末尾写一行 `:followup[…]`，这一行从正文和复制内容里隐藏，作为输入框里的灰字显示，按 Tab 填入。只在回复留下明显下一步时出现；有草稿、正在生成、回复停在工具调用上时不显示；子会话不加。不额外调用模型。停用插件即关闭。没装时标记原样显示。

## 待办清单卡

内置插件 `plume.todo`：

- agent 用 `todo_write` 维护清单（整张替换，同一时刻只有一项在做）。
- 清单卡片跟着对话：对话列够宽时浮在右上角，窄了放在输入框正上方；环境卡片开着时浮得下就排在它下面。标题行写当前在做哪一步、勾到第几项，点击收起 / 展开。
- 每项的记号区分：已完成、在跑、已暂停、失败、在做、未开始。标题行右边和停在那一步上一秒后出现动作按钮：在跑时暂停，失败时重试这一步，停下时继续。全部勾完卡片自动收走。
- agent 回答完清单还有「正在做」的项时提醒它一次；单独调用一次 todo_write、或 20 步没更新清单也会提醒。
- 转录里每次更新清单并进那段活，写成「更新清单 2/5 · 在做的那一项」。

## 划词引用

在回复里划选一段文字，可以引用到输入框（见 [输入框](composer.md#引用回复内容)），还能「在侧边聊天中提问」。
