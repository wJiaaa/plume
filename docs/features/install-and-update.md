# 安装与自动更新

Plume 的安装包、应用图标，以及应用内检查、下载、校验和安装新版本的流程。

## 安装包

- **macOS**：dmg（第一次手动安装）和 zip（给自动更新原地替换用），arm64 和 x64 各一份。钥匙串里有 `Plume Code Signing` 证书时用它签名，没有则 ad-hoc 签名；开启 hardened runtime。
- **Windows**：nsis 安装程序，x64 和 arm64 各一份；装给当前用户，可选安装目录；不签名。
- 安装包里带内置插件、插件 SDK（含 esbuild、TypeScript）和对应架构的 ripgrep，不带市场插件（装的时候从插件市场下载）；打包时核对每个原生模块和二进制的架构，对不上则打包失败。
- CI 打包可手动触发或推 `v*` tag 触发，产出各平台安装包和 `SHA256SUMS`。
- 不提供 Linux 安装包。

## 应用图标

- macOS 安装包使用带浅色、深色两套渐变底的头像图标；运行时的 Dock、窗口、Windows 安装包和欢迎页共用一张带浅色圆角底的头像图标，Dock 图标不随主题切换。
- 菜单栏 / 通知区域图标见 [窗口与布局](window-and-layout.md#菜单栏图标与-plume-链接)。

## 自动更新

- **关于页**（设置 › 关于）：顶上是头图（应用图标、名字、版本、是不是最新，旁边「检查更新」，有新版本时「立即更新」，下面「版本发布」打开发布页），下面是自动检查频率（1、4、6、8、12、24 小时，默认 6 小时，记在窗口本地）、运行环境，最后是这一版的更新内容（按界面语言只显示中文或英文那一段）。
- **发现新版本**：侧栏出现更新圆点；更新对话框显示新版本号和更新内容，「下载安装」后显示下载进度（可暂停、继续），失败时可重试。
- **校验**：下载完成后用同一发布附带的 `SHA256SUMS` 核对文件内容，对不上不安装。下载放在浏览器数据目录的 `updates/plume-update-<版本>/`。
- **安装**：
  - macOS：下载完成后「立即重启」，应用退出后由一个小脚本把新版本换到原位再启动；当前版本先挪开，新版本就位后才删除它，中途失败仍保留一个可启动的版本。重启会中断正在进行的对话。
  - Windows：下载完成后打开安装程序，按提示装完再重新启动 Plume；可「重新打开安装包」。
- 菜单栏图标的「检查更新…」打开关于页并立即检查。
- 新版本从 GitHub 仓库 `wJiaaa/plume` 最新的正式发布里取，草稿和预发布版不算；查不到时（没网、被限流、还没有发布）提示暂时查不到新版本。
