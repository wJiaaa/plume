# 内置浏览器与网页预览

在对话旁边打开网页、在回复里嵌入可交互的 HTML 页面，人和 agent 用的是同一个画面。

## 内置浏览器

内置插件 `plume.browser`（随应用发）：

### 面板

- 「浏览器」面板一个标签一页，后退、前进、刷新。加载时刷新按钮转圈；页面区还空着（新标签里输了地址、刚开的页）时正中转圈，已有一页在、正换去下一页时顶上浮一个小转圈，不挡着它。打开方式：面板区开始页点「浏览器」、⌘T（Windows 上 Ctrl+T），或让 agent 打开网址。
- 地址栏兼作搜索框：不是网址的交给设置里选的搜索引擎（支持自定义模板），打字时列出匹配的书签。
- 菜单：新标签页、关闭标签页、收藏和打开书签、检查元素、框选区域、开发者工具、缩放、视口尺寸（手机、平板、桌面预设或自填）。
- 每个会话有自己的标签，agent 只能看到和操作自己会话的页；同一页不开两份，最多 20 页；会话删除时它的网页一起关掉。
- 最近看过的三个会话和 agent 这一轮正在使用浏览器的会话保持页面挂载，其余收起，回去时按原地址重新加载。
- 标签可以弹到独立窗口再收回（重新加载同一地址，前进后退历史不跟随）。
- 页面崩溃 15 秒内自动重载一次；加载失败、被拦截时显示盖层。
- 只开 http 和 https；网页跳去别的协议时不跟，给一个按钮交给系统浏览器。页面的 Cookie 和登录状态存在单独的浏览数据里，跨重启保留，和系统浏览器分开；网页的权限请求一律拒绝。
- 本机 `.html`：地址栏打 `file://`、`~/` 或绝对路径，agent 还能给相对工作目录的路径。只提供这一个文件（旁边的样式、脚本、图片加载不到），每次刷新现读磁盘。

### 交给 agent

- 检查元素或框选区域后，面板底下出一张卡，写一句想怎么改；选中那块的地址、选择器、样式和 HTML 连同这句话接在输入框草稿后面，截图作为附件挂上，由人发送。
- agent 操作页面时显示光标和点击圈。

### 回复里的链接

- 右键回复里的网址可以「在内置浏览器打开」；`.html` 文件签悬停时多一个同样的按钮。
- 设置 › 浏览器里「默认打开链接」选内置浏览器后，点网址开在这里（Shift 点仍交给系统浏览器）。终端里 ⌘ 点网址也遵循这个设置。

### 给 agent 的工具

- `browser_open`：打开网址或本机 `.html`，先问人（「以后不再问」按站点或文件记），等页面显出内容（最多约 5 秒：空着的、只写着「加载中」的、字数还在变的页接着等）再交回页面文字和可操作元素。
- `browser_act`：读页面、点按、输入、悬停、滚动、按键、执行脚本、等文字或元素出现、后退、前进、刷新；点按前等元素可见、可点、未被遮挡，被挡时说出被谁挡。
  - 读页面：正文一次 8000 字（`maxChars` 最多 4 万），被截断时给出 `nextOffset` 接着读；`selector` 只读那一块的文字和元素，没匹配到时交回整页并说明；可操作元素最多列 120 个，多出的给个数。
  - 别的动作带 `read: true` 时连同之后的页面一起交回；点链接换了页的，等新页显出内容再读。
  - 同一条回复里的几次调用按顺序执行，有一次浏览器调用失败，后面的 `browser_act`（读页面除外）不执行，结果里说明原因。
- `browser_tabs`：列出、切换、关闭本会话的标签；agent 切标签不会把人看的标签切走。
- `browser_viewport`：改缩放和视口尺寸。
- `browser_screenshot`：截下当前页面交给 agent（不问人）。
- agent 操作期间页面弹出的 alert、confirm、离开提示由它应答（confirm 默认取消），结果写进工具结果；人自己浏览时仍是系统对话框。
- 转录里这几个工具并入读、跑、改的那段活，按「次」计操作网页。
- 随包带一份 `browser` 技能，装了技能插件时 agent 能读到。

### 设置 › 浏览器

默认打开链接的位置、地址栏的搜索引擎、新页面的缩放、书签管理。设置存在插件数据目录的 `browser.json`。

## 回复内交互网页

插件 `plume.preview`（从插件市场安装）：

- agent 用 `preview` 把 HTML 小工具、游戏、演示直接放进回复，传 `html`、`files` 或本地 `.html` 的 `path`；只保存提供的文件快照，不开放项目目录，源文件改了需重新调用。
- `check: true` 先检查：返回截图、脚本异常、控制台错误和高度，`width` 可查窄屏，长页分段检查；确认后只传 `id` 发布。抛异常或检查未完成的页面不发布。
- 生成参数时显示不执行脚本、不加载远程资源的静态草稿；检查到发布之间保留在原位，失败或未发布时收起。
- 页面跟随应用主题、按内容调整高度；长页可展开，也能移到面板里操作；可重跑。
- 页面状态：`plume.state` / `plume.setState(value)` 保存最多 16 KB JSON，重跑、切换会话或重启后恢复，改动在下一条人发的消息里作为页面数据交给 agent。
- 设计旋钮：`plume.tweak` 绑定设置对象，控件显示在页面下方（滑杆、颜色、开关、下拉），拖动即时生效，「发送修改」才调用模型，支持复位和对照初始值；每页至多 12 组、每组 12 个控件、每个下拉 12 个选项。
- 页内发送：`plume.send(text)` 只能在真实点击或表单提交处理器里同步调用，最多 2000 字；加载时、计时器里、程序点击、侧边面板中返回 `false`，只读会话不能发送。
- 「复制整页」把当前状态的页面拼成 PNG，不重新加载；超过 32767 图像像素高度时明确报错。
- 页面运行在独立沙箱，没有 Node、应用接口或磁盘访问；资源需内联、随 `files` 提供或用 HTTPS 地址。
- 应用不在前台时页面（对话里和面板里）停在当前帧以省电。
- 停用插件后卡片回到工具结果，重新启用恢复预览；删除会话时一并删除页面和状态。
