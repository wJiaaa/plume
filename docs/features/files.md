# 文件面板与文件交付

在对话旁边浏览和预览会话的文件，以及每一轮结束后汇总 agent 改了哪些文件、能审核和撤销的交付卡。

## 文件树

- 面板区的「项目文件」面板，⌘P（Windows 上 Ctrl+P）打开；有会话、有工作目录时才列出。
- 多源文件夹按源分组；支持展开、折叠、刷新、范围搜索、键盘导航、多选、悬停展开。
- 文件操作：行内改名（打开着的标签跟着换路径）、新建文件 / 文件夹、剪切 / 复制 / 粘贴、复制路径、创建副本（自动命名）、同名替换确认、移到废纸篓、永久删除、树内拖动移动或复制、从外部拖入复制。
- 右键还可以用默认目标打开、在系统文件管理器里定位、在终端中打开（需要终端插件）。
- 操作范围是会话工作目录、项目源文件夹和同一脉的会话（子智能体、侧边聊天、分叉、建议开出的新会话和它们的来源）的临时目录（`scratch/<会话 id>/`，回复里指向子智能体报告、截断前全文的链接能点开，分叉里复制过来的链接照样能点；别的会话的临时目录不行，`@` 补全和按名字找文件不搜它）；执行前复查真实路径，保护根目录及其祖先，拒绝越界、软链逃逸和递归拷贝。替换失败时恢复原文件；删除部分成功时，已删文件的标签同步关闭。

## 文件预览

- 「文件」面板，⌥⌘P（Windows 上 Ctrl+Alt+P）打开，每个文件一个标签，可弹出到独立窗口，重启后恢复。
- 内容只读：代码用只读编辑器显示（⌘F 查找）；Markdown 渲染显示，文档里的相对路径图片按文档所在目录解析；图片、PDF、音视频直接显示；预览不了的二进制文件（ppt、doc、odp、key 等）显示大小和「用默认应用打开」。
- 文档预览（内置插件 `plume.documents`）：Excel（xlsx、xlsm、xltx、xltm、xlsb、xls）、ODS、SQLite（sqlite、sqlite3、db）以表格显示，保留行号、列号、工作表切换，数字靠右排；每张最多 2000 行 64 列，工作簿最多 32 张表，数据库最多 64 张表或视图。Word（docx、docm、dotx、dotm）按页显示，保留页眉页脚、脚注、表格和图片，放在禁止脚本和外部资源的独立文档里，窄面板可横向滚动。PowerPoint（pptx、pptm、ppsx、ppsm、potx、potm）逐页显示，页宽跟着面板缩放，滚到附近才画；不取外部媒体，链接只在点击时交给系统浏览器，宏不执行。CSV 作为文本显示。单文件最多 64 MiB；表格和数据库在独立进程里解析，5 秒超时；数据库使用只读副本。
- 回复里的文件签、附件标记、Git 面板的「预览工作区文件」、终端里 ⌘ 点路径都在这里打开。
- 会话文件边界外的文件一般读不到；例外是上下文用量「记忆文件」里列出的那些（工作目录之上的指令文件、记忆插件的记忆文件），可以只读打开，不能改名、写入或在外部打开。

## 文件交付卡

内置插件 `plume.delivery`：

- 每一轮回复底下一张卡片，汇总这一轮实际留下的文件净变化（改回原样的不列）。以人发的消息为轮次边界，「继续」等系统消息不另切一轮。
- 默认列三个文件，可展开；悬停 700ms 打开预览、离开 160ms 后关闭，支持键盘聚焦预览和文件右键菜单。
- 「审核」打开本轮 diff 面板，不调用模型。
- 撤销单个文件或整轮改动：先确认，再复查文件；已有后续修改、修改链不连续、超出项目边界、来自命令的改动不能自动撤销。还有工具或后台命令可能写入时、同一项目里有别的会话在跑时拒绝撤销；撤销期间不能发起新一轮。
- 后台子 Agent 还没回来、结果还没送进会话、一次性的后台命令还在跑时，交付卡不挂出；开着的开发服务器、监视和没到点的定时唤醒不挡。
- 分叉出来的会话里，原会话那几轮的交付卡读不到改动快照。
- 撤回 / 编辑重发时连文件一起退回，见 [对话与回复渲染](conversation.md#编辑撤回分叉)。
