# 窗口与布局

主窗口的结构（活动栏、侧栏、会话区、面板区）、分屏、会话独立窗口和面板窗口、Windows 窗口外壳、菜单栏图标、`plume://` 链接、系统通知、提示条和菜单。

## 启动页

主窗口启动时先显示主题底色，120ms 后正中的 Plume 标志和细加载条淡入。启动页至少保留 900ms；后台连接、插件界面和工具列表准备好后进入主界面。开启「减少动态效果」时静态显示。独立会话、面板、截屏和钉图窗口不显示启动页。

## 顶行

- macOS 双击顶行空白处仍执行系统设定的动作。单屏欢迎页（不分屏、面板收起、欢迎区不用折行）放大或还原时，动画期间不让页面一帧帧重排：按下顶行时截下整页，页面同时说明每一块怎么跟着窗口挪（侧栏这几列上下贴边、中间空白拉开，欢迎区横向居中、纵向按顶上留白的比例挪，顶行左边不动、右边按钮贴右）。能拉开的只有纯色或磨砂的空白，拉开时把这一段截图重复摆开，不放大，磨砂的颗粒不会糊。动画时在主窗口上面盖一个外观一样的过渡窗口，按当帧尺寸摆这些截图块；主窗口藏着一次跳到终点，页面只排一次版，画好并核对过每块都在预料的位置后换回主窗口，对不上就用 0.15 秒淡出交接。截图只留在内存、不落盘；截图不可用（过期、窗口尺寸变过、找不到能拉开的空白）时照常交给系统缩放。
- 点主窗口绿色按钮进入或退出全屏时，桌面空间仍由 macOS 切换，过渡窗口和主窗口一起交给系统搬到全屏的桌面（退出时搬回），按系统给的时长从原窗框长到全屏（或反过来），做法同上；截图还在路上时最多等 0.1 秒，等了多久就从动画时长里扣掉。经键盘或菜单切换（没有截图）、开启「减少动态效果」、跨显示器切换，或全屏期间屏幕变化导致原来的窗框放不下时，沿用系统过渡；系统切换失败时撤掉过渡窗口、窗框放回原处。
- 窗口顶上一条，40px 高；最左边的活动栏 48px 宽：左端是红绿灯和后退、前进、侧栏开关（没有侧栏的界面不放开关），往右是当前界面的标题，压在窗口底色上，这一行的东西都在同一条中线上；活动栏、侧栏、对话和面板区都从它下面开始。侧栏和对话之间、对话和面板区（左右排时）之间，这一行里各竖一小截线，和下面的分隔线在同一列。
- 侧栏、对话、面板区（左右排时）连成一整块：贴着活动栏和顶上那一条，离窗口右边、底边 4px，外沿一圈圆角描边，栏和栏之间只有一道 1px 的线；面板区排在对话下面时，中间隔着它的标签行，仍是两块、隔 4px。
- 标题跟着下面那一栏的左右边走：对话是会话标题、代管标记、会话菜单和插件的会话工具栏，插件市场是它的工具栏，设置和插件的页面写名字；面板区的标签行在面板区上面，和它连成一条。侧栏开合时标题和卡片同一节奏滑，收起后停在窗口按钮右边。

## 面板区

- 会话区右侧的面板区由插件注册面板（终端、浏览器、Git、任务、调用轨迹、子 Agent、侧边聊天、计划、换肤工坊等），宿主自带「项目文件」和「文件」两个面板。
- 工作区右上角的面板开关开合面板区：只有一颗，开合时留在原处，开着时是「收起面板」，收着时是「打开面板」；面板区排在对话下面时，收起按钮在面板区自己的顶行。「+」新开一个开始页标签（已有开始页就切过去），在开始页的列表里点一项打开面板；空面板区仍保留开始页。
- 开合动画和侧栏一样：展开 340ms、收起 220ms，面板区贴着对话一起滑、中间不裂缝，内容跟着面板区走；左右排、上下排时标签、开始页和面板内容跟着淡入淡出（只动透明度），面板区盖满工作区时整块出现、不淡；对话顶行右端的按钮跟着卡片滑、不横着跳；开着的环境卡片不重挂，停靠和浮着只换一次（打开时点下去当场换好，收起时滑完再换），侧栏开合时也一样；可见的转录正文随对话栏一起变宽、变窄，达到阅读宽度上限后保持居中；屏外已完成的轮次沿用浏览器的布局跳过机制；开启「减少动态效果」时直接到位。
- 每个面板一个标签，当前标签随标题变化滚入可见区，鼠标中键点标签关掉它。面板区开着还是收着按会话记，切换会话时各回各的，重启后恢复；空白页上开着的，发出第一条成了会话后仍开着。宽度也按会话记：拖一个会话的面板区不影响别的会话，没拖过的按第一次显示时工作区的四成；空白页上拖过的，成了会话后照旧。关闭最后一个标签后这个会话的面板区收起，可从标题栏重新打开开始页。
- 面板跟随会话：工作区显示当前会话和它的面板（分屏时每屏各带自己会话的面板）；子会话的面板显示在父会话旁边。
- 全屏按会话，盖满工作区；窄窗口下面板区盖满工作区，放不下横排时改成上下排，拉宽后原样恢复，不丢面板、不重建内容、不改写保存的宽度和标签。
- 声明了常驻的面板（终端、浏览器等）切换会话时不重新挂载；声明了可恢复的面板按会话保存，重启后恢复；声明了可弹出的面板可以弹到独立窗口、再收回。
- 宿主快捷键：⌘P 项目文件、⌥⌘P 文件（Windows 上 Ctrl+P、Ctrl+Alt+P），插件面板的快捷键不能占用它们。插件面板的快捷键：⌘J 任务、⌘L 调用轨迹、⌘⇧R Git、⌥⌘S 侧边聊天、⌥⌘U 子 Agent、⌘T 浏览器、⌃` 终端（Windows 上 ⌘、⌃ 都换成 Ctrl，⌥ 换成 Alt）。

## 分屏

- 会话菜单（侧栏右键、行上的「…」）「打开方式 › 分屏」：工作区分成左右两屏，这段会话开在右边、焦点给它，原来的会话留在左边；已经分屏时换掉另一屏的会话；会话已经在某一屏上时只把焦点给它。最多两屏。窄窗口（侧栏变抽屉的那一档）里提示「窗口太窄，放不下左右两屏」、不分屏。会话标题栏上的菜单不列「分屏」（会话已经在屏上）。
- 每一屏是一个会话的完整一份：自己的标题栏（标题、会话菜单、插件的会话工具栏）、转录、输入框，和**自己的面板区**。面板区的开合、标签、宽度、全屏、上下排时的高度本来就按会话记，两屏各开各的、互不影响；每屏右上角各有一颗面板开关。两屏之间只有一道 1px 的线，挨着它的那一边不圆角。一屏窄到横排放不下面板区时，那一屏的面板区照单屏的规则改成上下排。
- 焦点：在另一屏里按下指针或按键时，焦点先换到那一屏，这一下照常落在按下的地方（按钮、输入框、面板）。焦点那一屏就是「当前会话」：面板快捷键、插件开面板、打开文件、`/` 命令、后退前进都按它办；两屏不换位置，只换焦点。焦点不在的那一屏标题栏淡一档，顶行以下整张卡片（对话、面板区和里面的终端、网页）盖一层半透明的底色压淡，换焦点时淡入淡出；只是一层纯色，不做模糊，流式输出和终端刷新时不额外费合成。两屏的会话在侧栏里都点亮；它们跑完、出错时不弹提示条、不记未读（人正看着）。
- 两屏之间可以拖宽度，每屏至少 420px，双击回到各占一半。工作区放不下两屏（缩窗口、窄窗口）时只显示焦点那一屏，拉宽后两屏原样回来。
- 每屏标题栏右端的「关闭这一屏」：关掉另一屏回到一屏；关掉焦点那一屏，焦点交给另一屏。另一屏的会话被删除、或在别处归档时那一屏收掉。
- 另一屏只放已有的会话：焦点那一屏可以是新对话的空白页（「新对话」、`/clear`），这时标题写「新对话」；焦点离开空白页时空白页收掉、回到一屏（空白页的草稿按项目留着）。
- 常驻面板（终端、浏览器等声明了常驻的）的内容整个工作区只有一层，按标签所在的那一屏摆：换焦点、在某一屏换会话、开合分屏时都不重新挂载。
- 分屏只在内存里，重启后回到一屏。

## 面板独立窗口

- 弹出的面板窗口没有浮起的卡片、不铺毛玻璃；标题栏贴窗口顶，左边粗体写面板名字，右边是置顶和收回，内容铺满。关窗口就是关掉这个标签（关闭前同样经过面板的关闭确认）。
- 面板窗口里要发消息、引用到对话的操作交回主窗口的来源会话处理。

## 会话独立窗口

- 会话菜单「打开方式 › 新窗口」：780×640，相对主窗口错开 52，收进所在屏幕，不记忆位置；同一会话再开只把已有窗口拿到前面。
- 整面对话底色，没有浮起的卡片、不铺毛玻璃。macOS 标题栏 44px 贴窗口顶，红绿灯在其中垂直居中；Windows 是顶上 32px 的带子。
- 标题栏：标题、插件的会话工具栏、置顶、在主窗口中打开（主窗口拿出来并选中这段会话，独立窗口关掉）。
- 侧栏点亮当前会话和已在独立窗口打开的会话。
- 独立窗口里打开面板、打开文件，交给主窗口的来源会话处理，主窗口最小化时一并拿出来。
- 没有侧栏和应用快捷键。
- 会话被删除、或在别处被归档时独立窗口关掉；本来就是归档的会话可以照常查看。
- 主窗口里要并排看两段会话用分屏（见上面「分屏」）。

## Windows 窗口外壳

- 隐藏系统标题栏，窗口顶部 32px 的带子里放系统按钮；侧栏和卡片在带子下面。卡片标题栏和插件页顶行不拖动窗口。
- 系统按钮颜色根据带子颜色调整，遮罩（看图器、对话框）打开时一起压暗。
- 窗口里不画原生菜单栏（按 Alt 也不弹），菜单里的快捷键照常可用。
- 面板窗口和会话窗口顶上的带子里是名字、置顶和收回，和系统按钮同一行，名字所在的空白可拖动窗口。

## 菜单栏图标与 `plume://` 链接

- macOS 和 Windows 上有菜单栏 / 通知区域图标：macOS 用模板图，Windows 用彩色图（多分辨率）。左键开关窗口，右键弹菜单。
- 菜单：打开 / 隐藏 Plume、新对话、最近会话（子菜单，没有时写「还没有会话」）、设置…、检查更新…（打开设置 › 关于并立即检查一次）、开机时启动（勾选项）、退出 Plume。文案跟随界面语言。
- macOS 上关窗口和「隐藏」一样只是收起（全屏先退出），点 Dock 图标恢复，退出用 ⌘Q 或菜单；Windows 上有通知区域图标时关窗口也是收起。
- 单实例：再次启动只把已开的窗口拿到前面。Windows 上设置了应用 ID（通知、任务栏归属正确）。
- 打包后的应用菜单不含重新加载和开发者工具。
- `plume://open-session?id=…` 打开指定会话（仅安装好的 macOS 包注册了这个协议）。

## 系统通知

- 任一 Plume 窗口都不在前台时，一轮跑完、出错或需要人批准时发系统通知；点通知进入那个会话（子会话的审批进入父会话）。
- 「完成」以会话真正闲下来为准：后台子 Agent、待送达的结果、还在跑的一次性后台命令还在时不报完成；开着的开发服务器、监视和没到点的检查、定时任务不挡。审批按调用去重。文案跟随界面语言。

## 提示条

- 提示条（toast）在窗口顶部、按整个窗口居中，不随侧栏开合挪位置；同类分组、计时消失、悬停暂停、有数量上限；插件也能发。
- 主窗口里人没在看的会话跑完、出错时报「「标题」已完成 / 执行失败」，卡片带「跳转到该会话」；子会话不报。
- 会话导出成 SQLite / Markdown 后带「在访达中显示」。
- 错误卡片可带「排查」：打开当前项目的空白页并把排查请求写进草稿（已有草稿时接在后面）。
- 对话操作、命令校验、附件、看图器、文件路径复制、模型配置导入导出等临时结果都用它；表单校验、未配置模型、agent 退出等常驻信息留在原位。
- 样式：行高 18px，上下 8px、左 12px 内边距（右边由按钮自带的留白补齐）；状态图标 14px；操作是 22px 的强调色图标按钮（跳转是箭头、在访达中显示是打开的文件夹、排查是对话加号）；关闭按钮常驻在最右端，22px、淡色，悬停才加底色；卡片间距 8px。

## 菜单

- 菜单卡片圆角 10px，内衬 4px，行高 32px，行左右 8px，图标与字间距 8px。
- 图标 15px、线宽 1.75，平时淡一档，悬停时和文字一起变实；危险项图标和文字一起变红。
- 分隔线两头缩 8px；分组标题 12px；行尾的勾为强调色 14px。
- 按下按钮时只换底色，不缩放。
