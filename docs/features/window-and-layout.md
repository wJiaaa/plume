# 窗口与布局

主窗口的结构（侧栏、会话区、面板区）、会话独立窗口和面板窗口、Windows 窗口外壳、菜单栏图标、`plume://` 链接、系统通知、提示条和菜单。

## 面板区

- 会话区右侧的面板区由插件注册面板（终端、浏览器、Git、任务、调用轨迹、子 Agent、侧边聊天、计划、换肤工坊等），宿主自带「项目文件」和「文件」两个面板。
- 标题栏右端的面板开关开合面板区。「+」新开一个开始页标签（已有开始页就切过去），在开始页的列表里点一项打开面板；空面板区仍保留开始页。
- 每个面板一个标签，当前标签随标题变化滚入可见区。宽度和收起偏好在窗口间共享；关闭最后一个标签后面板区收起，可从标题栏重新打开开始页。
- 面板跟随当前会话：工作区显示当前会话和它的面板；子会话的面板显示在父会话旁边。
- 全屏按会话，盖满工作区；窄窗口下面板区盖满工作区，放不下横排时改成上下排，拉宽后原样恢复，不丢面板、不重建内容、不改写保存的宽度和标签。
- 声明了常驻的面板（终端、浏览器等）切换会话时不重新挂载；声明了可恢复的面板按会话保存，重启后恢复；声明了可弹出的面板可以弹到独立窗口、再收回。
- 宿主快捷键：⌘P 项目文件、⌥⌘P 文件（Windows 上 Ctrl+P、Ctrl+Alt+P），插件面板的快捷键不能占用它们。插件面板的快捷键：⌘J 任务、⌘L 调用轨迹、⌘⇧R Git、⌥⌘S 侧边聊天、⌥⌘U 子 Agent、⌘T 浏览器、⌃` 终端（Windows 上 ⌘ 换成 Ctrl，⌥ 换成 Alt）。

## 面板独立窗口

- 弹出的面板窗口没有浮起的卡片、不铺毛玻璃；标题栏贴窗口顶，左边粗体写面板名字，右边是置顶和收回，内容铺满。关窗口就是关掉这个标签（关闭前同样经过面板的关闭确认）。
- 面板窗口里要发消息、引用到对话的操作交回主窗口的来源会话处理。

## 会话独立窗口

- 会话菜单「打开方式 › 新窗口」：780×640，相对主窗口错开 52，收进所在屏幕，不记忆位置；同一会话再开只把已有窗口拿到前面。
- 整面对话底色，没有浮起的卡片、不铺毛玻璃。macOS 标题栏 44px 贴窗口顶，红绿灯在其中垂直居中；Windows 是顶上 32px 的带子。
- 标题栏：标题、插件的会话工具栏、置顶、在主窗口中打开（主窗口拿出来并选中这段会话，独立窗口关掉）。
- 侧栏点亮当前会话和已在独立窗口打开的会话。
- 独立窗口里打开面板、打开文件，交给主窗口的来源会话处理，主窗口最小化时一并拿出来。
- 没有侧栏和应用快捷键。
- 会话被删除、或在别处被归档时独立窗口关掉；本来就是归档的会话可以照常查看。
- 主窗口一次只显示一个会话，不分屏。

## Windows 窗口外壳

- 隐藏系统标题栏，窗口顶部 32px 的带子里放系统按钮；侧栏和卡片在带子下面。卡片标题栏和插件页顶行不拖动窗口。
- 系统按钮颜色根据带子颜色调整，遮罩（看图器、对话框）打开时一起压暗。
- 窗口里不画原生菜单栏（按 Alt 也不弹），菜单里的快捷键照常可用。
- 面板窗口和会话窗口顶上的带子里是名字、置顶和收回，和系统按钮同一行，名字所在的空白可拖动窗口。

## 菜单栏图标与 `plume://` 链接

- macOS 和 Windows 上有菜单栏 / 通知区域图标：macOS 用模板图，Windows 用彩色图（多分辨率）。左键开关窗口，右键弹菜单。
- 菜单：打开 / 隐藏 Plume、新对话、最近会话（子菜单，没有时写「还没有会话」）、设置…、检查更新…（打开设置 › 关于并立即检查一次）、开机时启动（勾选项）、退出 Plume。文案跟随界面语言。
- macOS 上关窗口和「隐藏」一样只是收起（全屏先退出），点 Dock 图标恢复，退出用 ⌘Q 或菜单；Windows 上有通知区域图标时关窗口也是收起。
- 单实例：再次启动只把已开的窗口拿到前面。Windows 上设置了应用 ID（通知、任务栏归属正确）。
- 打包后的应用菜单不含重新加载和开发者工具。
- `plume://open-session?id=…` 打开指定会话（仅安装好的 macOS 包注册了这个协议）。

## 系统通知

- 任一 Plume 窗口都不在前台时，一轮跑完、出错或需要人批准时发系统通知；点通知进入那个会话（子会话的审批进入父会话）。
- 「完成」以会话真正闲下来为准：后台子 Agent 或待送达的结果还没收尾时不提前报完成。审批按调用去重。文案跟随界面语言。

## 提示条

- 提示条（toast）在窗口顶部、按整个窗口居中，不随侧栏开合挪位置；同类分组、计时消失、悬停暂停、有数量上限；插件也能发。
- 主窗口里人没在看的会话跑完、出错时报「「标题」已完成 / 执行失败」，卡片带「跳转到该会话」；子会话不报。
- 会话导出成 SQLite / Markdown 后带「在访达中显示」。
- 错误卡片可带「排查」：打开当前项目的空白页并把排查请求写进草稿（已有草稿时接在后面）。
- 对话操作、命令校验、附件、看图器、文件路径复制、模型配置导入导出等临时结果都用它；表单校验、未配置模型、agent 退出等常驻信息留在原位。
- 样式：行高 18px，上下 8px、左 12px 内边距（右边由按钮自带的留白补齐）；状态图标 14px；操作是 22px 的强调色图标按钮（跳转是箭头、在访达中显示是打开的文件夹、排查是对话加号）；关闭按钮常驻在最右端，22px、淡色，悬停才加底色；卡片间距 8px。

## 菜单

- 菜单卡片圆角 10px，内衬 4px，行高 32px，行左右 8px，图标与字间距 8px。
- 图标 15px、线宽 1.75，平时淡一档，悬停时和文字一起变实；危险项图标和文字一起变红。
- 分隔线两头缩 8px；分组标题 12px；行尾的勾为强调色 14px。
- 按下按钮时只换底色，不缩放。
