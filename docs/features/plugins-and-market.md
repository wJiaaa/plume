# 插件与「扩展」页

Plume 的大部分能力由插件提供：内置插件随应用发、不能停用；其余插件在「扩展」页里安装、更新、卸载，也可以让 agent 写一个新插件、改完当场生效。

## 「扩展」页

- 侧栏那一行叫「扩展」，图标是店面。页头是三个大字分类：**插件**、**技能**、**连接器**（选中的正文色，其余淡色，悬停稍亮），没有页标题、副标题。
- 三类都是卡片网格：三列（宽度不够时两列、一列），40px 图标、名字加一两行说明。
- **插件**：列出插件市场里可安装的插件。市场在网上（插件仓库 plume-plugins 发到 GitHub Pages 的目录），连不上时提示原因，列出已装的和上次读到的。筛选条最前面是「已安装」，筛出装上的插件（市场装的和本机添加的）；筛选签是图标加字，不显示数目。插件这一类没有搜索。
- **技能**：见 [Agent 扩展：技能](agent-extensions.md#技能)；工具条左边选项目，右边搜索、打开目录、刷新。下面是「从市场添加」：市场里的技能合集按货架排开。
- **连接器**（MCP 服务）：见 [Agent 扩展：MCP 连接器](agent-extensions.md#mcp-连接器)；工具条靠右是搜索、刷新、「添加」。下面是「从市场添加」：市场里的连接器按货架排开。
- 市场里的条目分三类，由插件 `package.json` 的 `plume.kind` 决定摆在哪一类：普通插件（缺省）、技能合集（`skill`，只带 `skills/`）、连接器（`connector`，只带 `.mcp.json`）。三类都是插件：安装、更新、停用、卸载和详情页都一样，「插件」那一类（包括「已安装」）只列普通插件。装上的技能合集、连接器在详情页的「设置」一节给出「去 扩展 › 技能 / 连接器」入口；连接器缺的密钥在连接器卡片上填。
- 内置插件不在列表里；只有加载失败的内置插件出现在「已安装」里（详情页不画开关、不给卸载，写明随 Plume 提供）。有插件没加载起来时，市场上的按钮切到「已安装」。

## 插件详情

- 卡片和详情共用插件根目录的 `icon.png`，没提供或加载失败才用默认标记。
- 介绍（README）和它的相对路径图片先从市场取，没装也能看；市场里没有的（本地上传的）读插件目录。https 图片走文档图片通道；相对路径的图只能是插件自己那一层里的 PNG、JPEG、GIF、WebP、SVG，单张 5 MiB。
- 「试试这样问」：读插件 `package.json` 里的 `plume.defaultPrompt`，装上并开着时列出，点一句开新对话并写进输入框；⋯ 菜单里有「立即试用」。
- 开关（停用 / 启用）、更新、卸载都在详情页。停用记在数据目录的 `plugins.json`。
- 「设置」一节：只和这个插件有关的设置画在这里（如 IM 机器人）；放在设置导航或产品页面里的，给出「去 设置 › …」入口；放进「扩展」另两类的，给出「去 扩展 › …」入口。

## 安装、更新与卸载

- 发给插件的文件（包里的、本机算指纹的、从本地上传时复制的）：`package.json`、`README.md`、`images/`、`icon.png`、`dist/`、`skills/`、`.mcp.json`、`LICENSE`，格式由插件 SDK 的 `@plumeai/plugin-sdk/manifest` 定，应用和插件仓库发市场都引它。
- 安装下载这台机器（平台、架构）的那份包，核对大小和 SHA-256，对不上或解不开都不装，装着的那份不动；解进数据目录的 `plugins/<目录名>`，agent 进程当场加载，不用重启；卸载当场撤下。
- 按版本号判断有没有更新：市场里的版本比装着的新才算（插件仓库保证发出去的版本内容不变）；自动更新默认开，启动后一会儿、此后每半小时、每次打开市场时各检查一次。
- 换插件（安装、更新、本地上传、卸载）时先把旧目录挪开再放入新目录，失败则全部还原、重新加载旧插件，成功后才删除旧目录。Windows 上改名会重试，文件被占用时提示关掉占用的程序。
- 带原生模块的插件（如终端）在 Plume 开着时也能更新、卸载：Windows 上原生模块按内容复制到数据目录的 `native-cache/` 再加载，插件目录不被锁住。
- 用 `PLUME_PLUGIN_PATHS` 指定的插件目录不能卸载。

## 创建插件

- 「扩展」页顶行右端的「创建插件」：
  - **新建插件**：开一个新对话，输入框里放好 `/plume-plugin`（这份写插件的技能随技能插件提供；技能插件没开着时先跳到它的详情页）。
  - **从本地上传**：把本机构建好的插件文件夹装进安装目录，和市场装的放在一处、能卸载；选的不是插件时有提示。
- `plume-plugin` 命令：插件 SDK 随应用发，Plume 生成 `~/.plume/bin/plume-plugin`（Windows 上另有 `plume-plugin.cmd`），用应用自己的运行时执行 `init`、`check`、`build`、`install`、`dev`、`link`，不需要本机装 Node 或 npm。
- 热加载：Plume 监视 `~/.plume/plugins` 和 `PLUME_PLUGIN_PATHS`，插件装进来、文件变了、被删了，按文件指纹当场加载、重新加载或卸下。

## 插件能做什么

插件可以注册工具、钩子（发送前、调用工具前后、组上下文、每步收尾、审批、压缩、撤回）、`/` 命令、工具卡片、审批卡、面板、页面、设置分区、输入框格子、环境卡片分节、会话菜单项、皮肤等。插件和 agent 在同一个进程里运行；插件死循环或崩溃会让 agent 进程退出，窗口提示「agent 进程已退出」。工具重名时后登记的生效，它撤下后前一个恢复。

## 内置插件

随应用提供、不能停用：工具（`plume.tools`）、沙箱（`plume.sandbox`）、自动审核（`plume.approval`）、向你提问（`plume.ask-user`）、系统提示词（`plume.prompt`）、上下文压缩（`plume.compaction`）、待办清单（`plume.todo`）、技能（`plume.skills`）、命令（`plume.commands`）、网页搜索（`plume.web`）、用量与状态（`plume.status`）、智能标题（`plume.title`）、建议新会话（`plume.spawn-session`）、Git（`plume.git`）、MCP（`plume.mcp`）、密钥加密（`plume.secrets`）、文件交付（`plume.delivery`）、运行诊断（`plume.diagnostics`）、文档预览（`plume.documents`）。

## 市场插件

终端、浏览器、网页预览、原生界面块、定时任务、计划模式、子智能体、侧边聊天、会话互通、代码审阅、钩子、记忆、语言服务、索引库、下一步建议、生图与画廊、屏幕截图、使用统计、会话摘要、拉取请求、SSH、换肤工坊、IM 机器人。各自的行为见对应模块文件。

### IM 机器人

插件 `plume.im`：在详情页的「设置」一节保存微信（iLink 服务地址、Bot Type、登录令牌）、飞书（App ID、App Secret、服务地域）、Telegram（Bot Token）的配置，每个平台可单独启用或停用。只保存配置，不连接平台、不收发消息、不创建会话。凭据经 `plume.secrets` 加密，界面只显示是否已保存，文本框失焦时保存，清除按钮删除已存密钥。

## 密钥加密

内置插件 `plume.secrets` 给插件提供加解密服务：密钥（MCP 令牌和请求头、OAuth 令牌、Git 平台令牌、SSH 主机库、IM 凭据）用 AES-256-GCM 加密成 `plume-sealed:v1:` 开头的文本，写回各插件自己的配置；钥匙存在 `plugin-data/plume.secrets/vault.key`（只有本人可读），第一次加密时生成。钥匙丢了时之前的值当作没填、需要重填；钥匙在却读不出时报错，不会换新钥匙覆盖。不使用系统钥匙串。它防的是配置文件被同步、拷走时带出明文，挡不住本机以同一用户身份运行的程序。
