# 项目脚本

在对话里管理并一键运行项目常用命令（内置插件 `plume.scripts`，随应用提供、不能停用；运行终端依赖 `terminal.exec`，工作树联动依赖 `session.worktree`）。

## 环境卡片快捷入口

只在属于某个项目的会话的环境卡片顶部（紧跟项目名与打开方式下方）显示，也可在环境卡片右键「显示哪些内容」中开关：

- **有已配置脚本**：整行无外框分割按钮，左半点击一键运行主脚本（按项目记忆上次运行的脚本，没有时取第一个非工作树初始化脚本），右半下拉列出全部脚本（行尾齿轮图标直接编辑）、`.plume/scripts.json` 待导入项与「添加脚本」。
- **尚无已配置脚本但仓库 `.plume/scripts.json` 有可导入项**：显示整行下拉菜单，可一键导入或添加脚本。
- **两者皆空**：显示整行「添加项目脚本」入口。

## 执行与环境变量

- 运行脚本时自动注入 `PLUME_PROJECT_ROOT`（项目主目录）；若当前会话在独立工作树目录运行，额外注入 `PLUME_WORKTREE_PATH`（当前工作树目录）。
- 未勾选「归档或删除会话时自动停止」的脚本，优先复用当前会话前台无子进程的空闲终端并切换目录、应用环境变量；勾选该项的脚本总是开启带标记的独立终端标签，会话归档或删除时自动关闭且跳过「前台程序仍在运行」确认框。
- 若脚本填写了预览地址并勾选「运行脚本时自动打开预览地址」，启动后自动调用链接打开方式打开预览地址。

## 工作树初始化

- 每个脚本配置范围（全局默认或单个项目）内最多指定一条脚本开启「新建对话工作树时自动运行」；开启新的会自动释放同列表内原有那条的初始化角色。
- **异步（默认）**：新建对话工作树后在后台终端标签启动，不抢焦点，立即进入对话。
- **同步（勾选「等待初始化完成后再启动对话」）**：首轮对话等待脚本退出；等待期间输入框上方显示状态条与「查看终端」按钮，点击即可打开并切到对应终端标签。脚本非零退出时弹出错误提示；`cmd.exe` 不支持等待退出码，会明确报错。

## 设置与 `.plume/scripts.json` 导入

- **设置 › 代码与版本控制 › 项目脚本**：可在「全局默认」与各已登记项目之间切换。项目未单独配置时继承全局默认；首次编辑/添加后保存为该项目独立配置，并支持一键「重置为全局默认」。
- **`.plume/scripts.json` 显式导入**：只读解析项目根目录下的 `.plume/scripts.json`（格式 `{ "scripts": [...] }`），绝不自动执行仓库脚本。解析失败时在设置页显示错误原因；解析成功时过滤已存在条目（按命令或忽略大小写的名称去重），供用户显式一键导入。
