# 终端与 SSH

在对话旁边开本机终端（插件 `plume.terminal`），以及管理远程服务器、配一个 AI 运维助手的 SSH 运维台（插件 `plume.ssh`）。两者都从插件市场安装。

## 终端

### 面板

- 「终端」面板一个标签一个 shell，shell 起在会话的工作目录里；标签标题写前台在跑什么（如「终端 1 · node」），可以开多个。
- 打开：面板区开始页点「终端」，或按 ⌃`；焦点在终端里时再按一次收起面板区。开出标签时才启动 shell。
- shell 比面板活得长：换会话、去设置页、弹出独立窗口后接上的还是原来那个，正在跑的构建不会断；最近输出按产生时的尺寸回放再适配新窗口。关掉标签或 shell 自己退出才结束。应用或 agent 进程重启后恢复标签时会新建 shell，运行中的进程和回滚输出不保留。
- shell 退出后标签留着，底下显示退出码和「新建终端」。
- 关标签时前台还有程序在跑会先确认，停在提示符上的直接关。

### 操作

- 查找：⌘F（Windows 上 Ctrl+Shift+F），回车 / Shift+回车前后跳。
- 右键复制、粘贴；粘贴走括号粘贴，粘进来的命令不会直接执行。
- ⌘ 点（Windows 上 Ctrl 点）网址：开在回复里网址开的地方（装了内置浏览器并设为默认时开在内置浏览器）；Shift 点交给系统浏览器。
- ⌘ 点 `src/app.ts:42` 这样的路径：在文件面板打开并定位；只认会话文件边界（工作目录和项目源文件夹）里找得到的文件，不认 `../` 开头的相对路径，相对路径拼不上时按结尾找唯一的一个；没有会话时路径不画成链接。
- 从访达或文件面板拖文件进来：打出加好引号的路径，末尾留一个空格，不直接执行。
- 文件树右键「在终端中打开」：复用该会话已有的终端，没有才新开，准备好后切换到所选目录；切目录的写法按 shell 区分（PowerShell、cmd、POSIX shell）。
- 回复里 shell 代码块的 ▶「在终端运行」交给这里执行（见 [对话与回复渲染](conversation.md#在终端运行)）。
- Windows 上每开一个标签读取注册表里的最新环境变量；Ctrl+Alt+S / P / U 不交给 shell，留给面板快捷键。
- 依赖随插件附带的原生组件；这台机器用不了时面板里写明原因，其他功能不受影响。

## SSH 运维台

插件 `plume.ssh`，侧栏多一页「SSH 主机」，从左到右三栏：

### 主机库（左栏，可收起）

- 新建、编辑、删除主机；收藏、分组、标签；按名称、地址或标签模糊搜索，按收藏或分组筛选；组内收藏的在前，再按最近连接。
- 点一台主机在中间开终端标签连上它，已有标签就切过去；「…」菜单可以再开一个连接。
- 从 Excel 导入：选 `.xlsx` 先预览，表头识别名称、地址、端口、账号、密码、分组，勾选要导入的行；已存在的主机、填写有误的行、带公式的行不能勾选；可按分组列自动建组。「下载模板」存到系统「下载」文件夹。
- 只支持密码登录。主机库（含密码、指纹）整份经本体的 `ctx.secrets` 加密存在插件数据目录；钥匙丢失解不开时，原文件挪到旁边、从空库开始。密码不显示在界面上，也不交给模型。

### 终端（中栏）

- 一个标签一条连接，可同时开多个。第一次连接时要核对服务器指纹，之后指纹变了直接拒绝连接。
- 支持查找、右键复制粘贴；离开这一页再回来连接不断，先回放最近输出。应用重启后连接不恢复。
- 资源占用：打开顶上的开关后每 5 秒读一次每条连接的 CPU、内存、磁盘和网速，显示在状态栏。
- SFTP：状态栏的文件按钮在终端右边打开文件面板，从家目录开始；双击进入文件夹、双击文件下载到「下载」文件夹（重名加序号）；拖本机文件进来上传到当前目录（同名覆盖）；新建文件夹、重命名（F2）、删除（Delete，只能删文件和空文件夹）；传输可取消；不支持传输文件夹。
- 问 AI：状态栏按钮或终端右键菜单，把选中内容（没选中就是最近 200 行）交给运维助手；发出前去掉控制序列，遮住已保存的密码和常见密钥。
- 批量命令：顶上按钮，勾选几条已连上的连接，把同一条命令在每条上各执行一次；执行前确认框列出每个目标的账号、地址、指纹和完整命令，确认后目标有任何变化都不执行；不经过 AI，命令和结果不进对话。

### AI 运维助手（右栏）

- 一个独立会话：能选模型、思考档位，能带附件；不进侧栏会话列表。「新开一段」开新的，「历史」回到之前的各段或删除当前段。
- 工具 `ssh_sessions`（看开着哪些连接）和 `ssh_run`（在其中一条上执行一条命令）只在运维助手里有。
- 每条命令弹审批卡（在助手输入框上方），写明在哪台服务器（名称、账号地址、指纹）、为什么执行、超时多久；命令可以先改再运行，改过时助手会被告知实际执行的版本。完全访问、帮我批准、「以后不再问」都不代批。批准后、发出前再核对一次连接身份，变了就不发。超时、断线或输出超限时结果记为「未知」，不自动重试。
- 助手等批准而人不在这一页时，侧栏「SSH 主机」那一行挂提醒，通知菜单里也列出。
