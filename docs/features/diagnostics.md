# 运行诊断与环境卡片

查看当前会话的后台任务、运行记录、调用轨迹和环境状态（内置插件 `plume.diagnostics`），以及会话摘要（插件 `plume.summary`）。

## 任务面板

- 面板区开始页选「任务」，或按 ⌘J（Windows 上 Ctrl+J）。
- 内容：待办清单、后台任务、工具运行记录（虚拟列表）；可按状态、命令、参数或输出筛选。
- 后台任务：已结束的保留到应用退出；展开可读最新日志（尾部 256 KiB，文件预览最多读开头 2 MiB，完整日志可交给编辑器打开）；「停止」「强制结束」只作用于选中的任务。
- 端口发现：只认任务进程树里的监听端口，结合输出里打印的本机地址补全 URL。任务那一行挂端口签，面板列出服务地址，可以打开（装了内置浏览器时开在内置浏览器）、交给系统浏览器、复制。只在任务面板或环境卡片打开时才查找。
- 点对话里「后台命令完成」那一行，直接定位到该任务的输出；运行详情可跳到轨迹或原工具卡片。

## 调用轨迹

- 面板开始页选「调用轨迹」、按 ⌘L（Windows 上 Ctrl+L），或会话菜单「查看调用轨迹」。
- 按轮次串起真实请求、系统提示词、思考、回复、工具、审批、重试和压缩；可按来源、状态、文字和时间范围筛选，查看关联记录、输入输出和原始信息。
- 导出 JSON 或 Markdown。
- 时间线按请求 / 工具两行显示；详情在窄面板里替换列表，够宽时与列表并排，中间分隔可拖动或用左右方向键调整（360–720px，只在本次打开有效）。
- 观察数据存在插件私有的 `diagnostics.db`，不保存供应商配置、请求头或密钥；撤回时截断，删除会话时清除。启用前的历史只还原已有消息与工具记录。

## 环境卡片

- 点标题栏的「环境」开关打开。内容分节：打开方式、在跑的后台任务、子 Agent、侧边聊天、压缩记录、引用；其他插件加的节：批准过的计划、建议的新会话、拉取请求、摘要、定时唤醒和监视。
- 右上角选择显示哪些节，空的节不占位。
- 放置：对话列宽度足够（让出 324px 后正文还有 520px）时停靠在右侧占 300px 一列，转录和输入框让位；不够时浮在转录右上角；不会放到输入框上方；内容太长时自己滚动。
- 卡片收着时，开关上的圆点和说明提示待触发的唤醒、在跑的监视、待决定的建议新会话。
- 拉取请求一节：当前分支在「我的 PR」里、仓库是这个目录的 origin 时出现，带检查状态，点了去拉取请求页选中它。

## 会话摘要

插件 `plume.summary`（从插件市场安装）：

- 在环境卡片的「摘要」一节写一段话，说清这个会话在做什么、做到哪、下一步是什么（最多两百来字，语言跟对话一致）。
- 一轮结束、静下来一分钟后在后台写一次；人至少说过三句话才写第一份，之后人每多说两句才更新。子会话不写。
- 材料只有人和 agent 说的话加新建或改过的文件名，不送工具输出；已有一份时只送之后的消息和上一份。
- 显示：还没写出来时不占位；正在写时画骨架；有新消息未更新时标「这一轮结束后更新」；失败时留「重试」。
- 模型在设置 › 智能体 › 会话的「会话摘要模型」里选，不选或选的模型没了用会话自己的模型。每次更新多调一次模型，用量不记在会话名下。
- 摘要存在插件数据目录，删会话时一起删。不想要这笔花销可以停用或卸载插件。
