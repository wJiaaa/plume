# 运行诊断与环境卡片

查看当前会话的后台任务、调用轨迹（内置插件 `plume.diagnostics`），以及环境卡片（内置插件 `plume.environment`）。

## 后台任务面板

- 面板区开始页选「后台任务」，或按 ⌘J（Windows 上 Ctrl+J）。
- 内容：后台命令和这个会话派出去的子 Agent，分「运行中」「已结束」两组（已结束的能收起），一项一张卡片，新的在前。还在跑的右边是跑了多久和停止键，叫停后还没停下时停止键换成「强制结束」（先确认）；结束的写结果（完成、已停止、失败或退出码）。命令的卡片展开先是 `$ 命令`，下面是输出；输出超过 256 KiB 只显示尾部，提示后面有「查看完整输出」。子 Agent 的卡片点了打开子 Agent 面板里它那一页。待办清单不在这里列；工具运行记录在调用轨迹里看。
- 后台任务：已结束的保留到应用退出；展开可读最新日志（尾部 256 KiB，文件预览最多读开头 2 MiB，完整日志可交给编辑器打开）；「停止」「强制结束」只作用于选中的任务。
- 端口发现：只认任务进程树里的监听端口，结合输出里打印的本机地址补全 URL。任务那一行挂端口签，面板列出服务地址，可以打开（装了内置浏览器时开在内置浏览器）、交给系统浏览器、复制。只在后台任务面板或环境卡片打开时才查找。
- 点对话里「后台命令完成」那一行，直接定位到该任务的输出。

## 调用轨迹

- 面板开始页选「调用轨迹」、按 ⌘L（Windows 上 Ctrl+L），或会话菜单「查看调用轨迹」。
- 按轮次串起真实请求、系统提示词、思考、回复、工具、审批、重试和压缩；可按来源、状态、文字和时间范围筛选，查看关联记录、输入输出和原始信息。
- 钩子经过：工具调用、模型请求的详情里列出这次经过的钩子（工具调用是 `tool.execute`，会改动的再加每次审批的 `tool.approve`；请求是组上下文的 `model.context`），层从外到内一行一层：插件、order、做了什么（往里交、自己给了结果没往里交、出错，以及改了参数、改了结果），最后一行是本体执行了、按外层的设定停下（如计划模式的只读拦下写文件），还是没走到。只记有没有改，不记改成了什么。消息写进会话前经过的 `prompt.submit` 单独成一条（来源「钩子」），被拦下的那条消息也在这里看得到。`step.end`、`context.compact` 不记。只有挂了插件层的钩子才有这些记录。
- 导出 JSON 或 Markdown。请求实际发出的消息和工具表在打开那次请求的详情时才读取，不在列表搜索和导出里。
- 时间线按请求 / 工具两行显示；详情在窄面板里替换列表，够宽时与列表并排，中间分隔可拖动或用左右方向键调整（360–720px，只在本次打开有效）。
- 观察数据存在插件私有的 `diagnostics.db`，不保存供应商配置、请求头或密钥；请求里的系统提示词、工具表和消息按内容去重，每份只存一次；撤回时截断（不再被用到的内容一并删掉），删除会话时清除。启用前的历史只还原已有消息与工具记录。

## 环境卡片

- 点标题栏的「环境」开关打开。页头放系统打开方式和项目脚本，紧接版本控制区（分支切换、Git 快捷操作，由 `plume.git` 提供，不画组标题）。
- 各类内容按节分开展示，各有自己的分组标题（默认带数量计数；「子智能体」和「关联会话」标题后不显示数量）：运行中的后台命令/服务/监视在「后台任务」，检查、定时任务和轮询在「定时任务」，子智能体在「子智能体」（由 `plume.subagents` 提供，点了在「子 Agent」面板里打开），批准的计划在「计划」，从当前会话派生的关联会话（建议卡开出的、直接开、offer、移交、计划交给新会话、侧边聊天开新会话与分叉）在「关联会话」（停止、完成、出错或归档后仍保留显示），当前分支的拉取请求在「拉取请求」，对话里附过的文件和图片在「引用」；压缩记录在页脚。侧边聊天不进入环境卡片；没有内容的分组不占位、不留分隔线。
- 分组可以收起：点分组标题（整行都能点）收起或展开这一组，箭头跟在标题后面，展开时只在悬停或键盘聚焦时露出。收起后只剩标题，标题总带条数（「子智能体」「关联会话」也带）；组里有在跑的，标题上再挂一个绿点。收起哪些按分组记着，换会话、重开应用都保留；收起不等于藏起来，开关上的圆点提醒照旧。
- 各节共用同一种行：图标（子智能体显示对应智能体头像和状态表情）与人写的说明在左，端口、时间、状态等机器事实在右（定时任务日期时间较长，以双行显示在标题下方）；运行中只在图标右下挂绿点，检查倒计时在行底留白处画细线。悬停后出现「停止」或「取消」。
- 没有「全部停止」：会话闲着时输入框上没有停止键，挂着的服务、监视在「后台任务」里逐项停，检查、定时任务和轮询在「定时任务」里逐项取消，不问。要一次清掉，归档、删除会话或退出应用：后台任务会停掉（记录留着），检查和定时任务会取消，安排它们的调用标「已停止」。
- 卡片没有设置按钮：在卡片上右键选择显示哪些内容（链接、输入框、选中的字照旧用自己的菜单）。空内容不占位；各项都藏起来时卡片里留一行「选择显示的内容」。
- 放置：一块 280px 宽的实底浮层，总是浮在转录右上角，转录和输入框不让位；侧栏、面板区开合时卡片不重挂、不闪；开合从右上角由 0.98 倍放大淡入、原路缩回淡出，收起时等动画播完才拆掉；不会放到输入框上方；内容太长时自己滚动。
- 卡片收着时，会自己叫醒会话的监视、待触发检查、定时任务以及运行中/排队中的子智能体经 `attention` 点亮环境开关。普通长跑服务不算；尚未开始的新会话建议只留在原本的建议卡，既不进环境卡片也不点亮开关。
- 当前分支在「我的 PR」里、仓库是这个目录的 origin 时，拉取请求作为「拉取请求」里的一条出现，右端带检查状态，点了去拉取请求页选中它。
