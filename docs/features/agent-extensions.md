# Agent 扩展：命令、技能、连接器、钩子与记忆

用户扩展 agent 行为的几种方式：自定义 `/` 命令、技能、MCP 连接器、钩子和记忆。

## 自定义命令

内置插件 `plume.commands`：

- 把常用指令写成 Markdown 文件，在输入框敲 `/名字` 发出；发送时展开成文件正文，对话里显示的就是发给 agent 的全文。
- 读四个目录，同名时排在前面的生效：`<项目>/.plume/commands`、`~/.plume/commands`、`<项目>/.claude/commands`、`~/.claude/commands`。子目录是命名空间（`git/commit.md` 叫 `/git:commit`）；名字只能用小写字母、数字和连字符。
- frontmatter：`description` 显示在菜单里，`argument-hint` 在未写参数时灰字提示；`deliver` 决定 agent 正在跑时怎么送出——`prompt`（默认）和 `followUp` 排到当前这一轮之后，`steer` 直接插进正在跑的这一轮。写错的值按默认发并在设置页报出。
- 正文里 `$ARGUMENTS`（或 `$@`）代表命令后的全部内容，`$1`、`$2` 取第几个参数（引号括起几个词算一个）；一个占位符都没写时，参数接在正文末尾。
- 命令文件每次打开菜单、每次发送都现读，改完立即生效。
- `/commands` 打开设置 › 命令（「Agent 能力」组），盖住同名的命令文件；带参数时报错并保留输入。
- 设置 › 命令：顶上选看个人的还是某个项目的命令；可以新建（选存进项目还是个人目录）、打开编辑、删除（移到废纸篓）、打开命令目录。下面只读的「内置」一段列出产品和插件自带的命令。加载失败、被同名遮住的命令会标出来。

## 技能

内置插件 `plume.skills`：

- 技能是一个目录，里面放 `SKILL.md` 和它要用的脚本、模板。每一轮把可用技能的名字和描述列进系统提示词，正文在 agent 调用 `skill` 工具时才给，同一份正文在上下文里只给一次（压缩后可重新给）。
- 用法：agent 看到任务对得上时自己调用；输入框 `/技能名 补充说明` 点名使用；话里写 `/skill:名字` 也算点名；`@` 搜索技能会插入 `/skill:名字`。
- 读取位置（同名时靠前的生效）：`<项目>/.plume/skills`、`<项目>/.claude/skills`、`<项目>/.agents/skills`、`~/.plume/skills`、已安装插件附带的 `skills/`、`~/.agents/skills`。在设置页点过「改用那个」的按人的选择。
- frontmatter：`name`（小写字母、数字、连字符，缺省用目录名）、`description`（必填，通常 40 字符以上，最多 1024）、`disable-model-invocation: true`（不让 agent 自己挑，只能从 `/` 菜单点名）、`allowed-tools`（技能生效期间只允许这些工具，到人说下一句或换技能为止；Claude Code 的工具名会换成对应工具，括号里的范围按整个工具放行，对不上的名字不放行任何调用）。
- 正文里 `${CLAUDE_SKILL_DIR}` 换成技能目录，`${CLAUDE_PLUGIN_ROOT}` 换成带来它的插件目录。
- agent 可以用 read 读 `skill://技能名`（正文）、`skill://技能名/`（目录）、`skill://技能名/references/x.md`，只读、出不去技能目录。
- 没有可用技能时，`skill` 工具和目录段一起隐藏。技能每轮现读磁盘，改完下一轮生效。
- **扩展 › 技能**：上方选一个项目（不选只列个人的和插件带来的），按目录分组，卡片网格显示；可以开关（关掉的淡一档，不进目录、工具和菜单）、整组全部关闭 / 开启、打开 `SKILL.md`、删除（整个目录移到废纸篓；插件带来的不能删）。加载失败、描述太短、`allowed-tools` 未按原意生效的会标出；被同名遮住的单列一块，能对比两份、点「改用那个」。

## MCP 连接器

内置插件 `plume.mcp`，随应用提供、不能停用。界面上叫「连接器」，在「扩展 › 连接器」里管理：

- **两种服务**：本地进程（stdio，填命令、参数、环境变量；进程使用登录 shell 的环境，`npx`、`uvx` 能找到）；远程 HTTP（填地址，传输方式选 Streamable HTTP 或 SSE，令牌写在请求头里）。
- **工具**：连上后它的工具以 `mcp__<名称>__<工具名>` 出现（太长或含特殊字符时截短加哈希）。每次调用前弹审批卡，「以后不再问」记住单个工具。
- **只读声明**：默认照样每次问；打开「信任它的只读声明」后，帮我批准模式下它标为只读的工具不再确认；标为破坏性的始终确认。
- **断线重连**：从 0.5 秒起翻倍、最长 30 秒、最多 8 次，稳定 30 秒后计数清零；重连期间工具保留，调用最多等 15 秒。无动静 5 分钟算超时。
- **工具多时按需搜索**：所有服务的工具估算超过 3000 token 时，工具表里只留 `mcp_search` 和 `mcp_call`，系统提示词列出服务和工具名；可把常用服务设为「常驻」，工具一直直接给 agent。
- **资源**：agent 用 read 读 `mcp://`（列出连着的服务的资源）和 `mcp://<名称>/<资源>`；只读文字，不问人。
- **prompt**：服务提供的 prompt 变成命令 `/mcp:<服务>:<prompt> 参数`，只有一个参数时整段给它，否则写成 `名字=值` 或按顺序。
- **服务中途要人填表**：输入框上方弹出表单，「提交」「拒绝提供」「取消」三个出口；只由人填，完全访问和「以后不再问」都不代填；多个会话同时用同一台服务、说不清该问谁时替人答「不给」。
- **结果**：太长的截断，全文存进会话临时目录的 `mcp-results/`；结果里的图 200 KiB 以内直接给模型，5 MB 以内存进 `mcp-images/` 给模型路径，超过 5 MB 只说明；只把 PNG、JPEG、GIF、WebP 交给模型；音频只写说明。卡片上都能看到图。
- **嵌入文档**：服务返回的 Word、Excel/ODS、SQLite 在结果下方显示文件卡片，点「预览」用统一只读预览；每次结果最多 16 份、合计 64 MiB，按会话存快照，删会话时清理；资源链接不自动下载。
- **`${NAME}` 空位**：命令、参数、变量、地址、请求头里可以写 `${NAME}`，先取卡片上填的值，再取登录 shell 的环境变量；都没有时卡片标「缺少密钥」，填好、焦点离开就启动。
- **OAuth**：远程服务请求头里没写 `Authorization` 的按 OAuth 处理：卡片标「需要登录」，点「登录」在浏览器授权、本机回调后自动连上；令牌过期用刷新令牌换新；要更大权限时重新登录；⋯ 菜单可退出登录。
- **每个会话独立**：打开后每个会话第一次用到时各起一份进程，会话删除时关掉；适合在进程里保留状态的服务。
- **卡片**：状态点、「N 个工具」可展开、连不上时摊开原因和 stderr 最后几行、重新连接、⋯ 菜单。添加在弹窗里；改已有的在卡片上就地改（名字、命令、参数、变量、三个开关），焦点离开那一块时保存。缺值、要登录、连不上或展开的卡片占满一行。
- **密钥**：名字像密钥的环境变量和请求头（`…_TOKEN`、`…_KEY`、`Authorization`）不再显示原值，编辑时留空即保留；它们和 OAuth 令牌经内置插件 `plume.secrets` 加密存储。配置在插件数据目录的 `servers.json`（0600）。
- **Magpie 分发的服务**：见 [设置：Magpie](settings.md#magpie)。

## 钩子

插件 `plume.hooks`（从插件市场安装），写法与 Claude Code 的钩子兼容：

- **九个事件**：`SessionStart`、`UserPromptSubmit`、`PreToolUse`、`PermissionRequest`、`PostToolUse`、`PostToolUseFailure`、`Stop`、`StopFailure`（出错、被停、用满步数、原地打转、退出应用时被打断）、`SessionEnd`（删除、归档、换项目、退出应用；退出时最多等 2 秒）。
- **输入输出**：钩子从 stdin 读 JSON（字段同时给 camelCase 和 snake_case）。退出码 0 读 stdout 的 JSON；退出码 2 拦下，原因取 stderr；其他退出码算运行失败，记进运行记录，这一步照常往下走。
  - `PreToolUse`：`permissionDecision` 可说 deny / ask / allow（多条取最严），`updatedInput` 改参数；allow 跳过审批卡，但提权仍要人批。
  - `PermissionRequest`：`allow` 或 `deny`；拒绝就不弹卡，放行只放这一次；提权只认人批，提问、计划等只能由人答的卡不问钩子。
  - `UserPromptSubmit` 拦下时消息不发给 agent，原因弹提示条。
  - `Stop` 用 `decision: "block"` 加 `reason` 让 agent 接着干，每轮最多续三次。
  - `additionalContext` 交给 agent：会话开始、提交、Stop 的附在消息后，工具前后的接在工具结果后。
  - `StopFailure`、`SessionEnd` 只是通知，输出不读。
- **匹配器**：用 `|` 分隔或写正则。工具类事件按工具名（`Bash` 和 `bash` 都认）；`SessionStart` 按 `startup` / `resume`；`StopFailure` 按 `error` / `aborted` / `max_turns` / `stalled` / `interrupted`；`SessionEnd` 按 `deleted` / `archived` / `moved` / `quit`。
- **运行方式**：「进程」（参数每行一个）或「Shell 命令」；「高级」里设超时（默认 60 秒）和状态消息；勾「后台运行」不等它跑完。命令里可用 `${CLAUDE_PROJECT_DIR}`（或 `${PLUME_PROJECT_DIR}`）、`${CLAUDE_SESSION_ID}`；钩子在项目目录里以登录 shell 的环境运行。
- **用户钩子与项目钩子**：用户钩子存在插件数据目录的 `hooks.json`，对所有项目生效；项目钩子写在项目 `.plume/config.json` 的 `hooks` 里，要先在设置页逐条「信任」才会运行，没信任的跑到时只记一笔「已阻止」。信任按内容指纹记（命令、参数、匹配器改了要重新信任，开关不算），记录在插件数据目录的 `hook-trust.json`；在设置页亲手新建、编辑的项目钩子直接算信任。工作树里的会话按工作树目录信任。
- **设置 › 钩子**（「Agent 能力」组）：左上角切换用户 / 某个项目，可以开关、新建、编辑、删除、信任。
- **待审核提示**：会话目录里有没信任的项目钩子时，输入框上方一行提示，「去审核」直接打开该项目的钩子设置。
- **运行记录**：每个会话最多留最近 500 条；哪一轮有钩子被拦下、失败或超时，那条回复底下多一个「钩子」按钮，点开看每条的结果和原因。钩子失败不弹提示条。

## 记忆

插件 `plume.memory`（从插件市场安装）：

- **用户记忆**：跟着人走的偏好，在设置里手动添加，进每个会话的提示词。
- **项目记忆**：按项目分，两份来源：agent 用 `learn` 工具记下的教训（`learned.md`，可手改；转录里写「学习 <前 40 字>」）；后台总结（`MEMORY.md`）。
- **后台总结**（默认关）：最近在用的那个项目空闲满 5 分钟（没有会话在跑）时，从 12 小时前到 30 天内结束的会话里提炼约定，合并进 `MEMORY.md`；同一项目一天最多一次；只有完整回复才写入，截断或中断时保留旧记忆；写了东西才在该项目最近的会话上提示一条。材料是用户和助手说的话（不含工具结果，先去掉形如密钥的串）。只总结开在项目里的会话；git 工作树里的会话算进主检出那一份。
- **冻结**：每个会话冻结一份记忆；会话中途的 `learn`、后台总结或手改文件不立即生效，压缩、撤回、重新载入或换模型重建历史时重新读取；在设置里删改的从下一次请求起生效。
- 每条记着最后一次进提示词的时间。
- **设置 › 个性化 › 记忆**（在全局指令和语气之间）：三个开关（用户记忆、项目记忆、自动沉淀项目记忆）；加、删用户记忆；选项目查看、逐条删除、丢掉后台总结的那份或全部忘掉，删除前确认。关掉项目记忆后不读也不记，模型看不到 `learn`。
- 后台总结的模型在设置 › 智能体 › 会话的「记忆整理模型」里选，不选用默认模型。
- 记忆文件出现在上下文用量的「记忆文件」一行里，可以点开查看。
