# 外观与皮肤

Plume 的主题、配色、字体和代码外观（设置 › 外观），以及接管配色的换肤工坊插件和首页背景。

## 主题与配色

- 主题：浅色、深色、跟随系统；命令面板里也能切换。深浅判断跟随系统外观设置。
- 浅色主题、深色主题各自可选预设，并调强调色、背景、前景、UI 字体、对比度。
- 外观设置由主进程存在数据目录的 `appearance.json`，只记用户改过的字段；窗口打开前就按它设好主题，避免闪烁。

## 代码外观

- 浅色代码高亮、深色代码高亮：分别作用于浅色、深色模式下的文件预览和代码块，提供 9 套浅色、10 套深色主题。
- 行内代码：底色和字色跟界面、跟代码主题或自定义（浅色 / 深色底色和字色分别设，可「跟着底色」）；可加描边。
- 代码字体（用于文件预览、代码视图与终端；本机没装的字体会标出，可写自定义字体栈）、代码字号、行高（倍数）、字距（em）。
- 这些设置实时生效。

## 偏好设置

- 使用指针光标：悬停交互元素时显示指针。
- 减少动态效果：三态（开、关、跟随系统）。
- UI 字号：调整界面基准字号，标题等字号随之缩放。
- +/- 标记：Git 面板和工具卡片展开后的 diff（插件用 `ui.FileDiff` 画的也算）用颜色或 +/− 标记显示；选 +/− 时符号标在代码那一格，没改的行垫一个空格。
- 字体平滑：使用 macOS 原生字体抗锯齿。
- 窗口毛玻璃：主窗口的侧栏和四周透出 macOS 窗口材质，关掉后用不透明主题色。
- 偏好的说明文字统一使用说明字号（默认 12px）。

## 恢复默认

- 两处「恢复默认」：代码外观一节单独恢复，外观页底部整页恢复。都是清除手动调整，回到当前皮肤或默认外观；整页恢复还会关闭字体平滑、撤销背景图选择。
- 皮肤插件仍决定用户未覆盖的默认外观。

## 换肤工坊

插件 `plume.skin-studio`（从插件市场安装），用 12 色数据皮肤改变配色，不改布局和字体：

- **打开**：输入框底部的调色盘按钮，或面板列表里的「换肤工坊」。
- **画廊**：内置八套配色（薄荷清晨、蜜桃奶油、石墨、午夜莓果、深海青，晴空、薰衣草雾、青瓷三套色调皮肤），浅色五套、深色三套，每套的外圈（停靠侧栏）都比会话窗暗一档；纯白的浅色用「系统外观」的「浅色」，不另做皮肤。色调皮肤由一个色相和彩度经 OKLCH 推出 12 色，窗口外圈和停靠侧栏是粉彩渐变（皮肤 token `root-image`），正文区是近白的纸面；要颗粒质感另开「磨砂」。每张卡片是用真实色值画的缩略图（侧栏、主区、文字、强调色），正在用的打勾。点卡片立即应用并保存选择，面板不进入加载状态；下次启用插件时自动恢复；工具调用和其他窗口的更改同步过来。
- 每套皮肤的 `base` 决定浅色或深色模式，不跟随系统切换。
- 皮肤接管时，外观页显示「当前皮肤」名，界面配色和深浅模式只读，字体、代码外观等仍可改；皮肤只在内存里临时覆盖，不改写用户保存的外观偏好。
- **系统外观**一行：「跟随系统 / 浅色 / 深色」就是外观页的三张主题卡片，点了撤下工坊皮肤、改用户的主题偏好（经 `ui.setTheme`），两边同步；没用工坊皮肤时亮的是外观页当前选的那张。「恢复原外观」退出工坊管理，恢复原偏好或其他已启用皮肤。停用插件同样恢复。
- **保存**：先应用一套皮肤，再点画廊末尾的虚线卡片命名保存副本；每次都新增，不覆盖。
- **导入**：「系统外观」一行的剪贴板按钮，粘贴 JSON，即时校验并预览，「导入并应用」。
- **复制**：悬停卡片时名称右侧的复制按钮，复制 `{ name, base, colors }`，有底纹时带上 `backdrop`。
- **删除**：自定义作品可删（先确认），内置的不能删；删掉正在用的作品后恢复原外观。
- **格式**：`name`（非空，最多 80 字）、`base`（`light` / `dark`）和完整的 12 个颜色（根背景、主内容背景、浮出侧栏背景、卡片和浮层背景、悬停背景、激活背景、主要 / 次要 / 提示文字、强调色、强调底纹、描边），全部 `#RRGGBB`；可选 `backdrop: { from, to }` 给外圈铺从 `from` 到 `to` 的斜向渐变。主要、次要文字与六种背景（有底纹时加上 `from`、`to`）的对比度至少 4.5:1，提示文字至少 3:1；不满足时不保存、不应用。
- **让 AI 设计**：「系统外观」一行的画笔按钮，把设计要求追加到面板所属会话的输入框（新对话追加到当前输入框），保留已有草稿、不自动发送。模型用 `skin_studio_theme` 工具列出、应用、保存、删除皮肤或恢复原外观；主题（跟随系统、浅色、深色）是用户的设置，工具不改。
- 作品和当前选择存在插件私有数据目录。连接失败时面板显示原因和重试按钮。

## 首页背景

在换肤工坊顶部的「首页背景」卡片设置（外观页没有这一节）：

- 选择或拖入图片（PNG、JPEG、GIF、WebP，不超过 20 MB），可预览、清除。
- 铺满 / 平铺、五档浓度（8%–52%）、背景效果、显示位置（新对话、对话中），都是分段按钮。
- 质感：「无 / 磨砂」。磨砂给整个窗口（外圈、停靠侧栏和对话区）叠一层很淡的细噪点，深浅颗粒相互抵消，不把底色拉灰；不看皮肤、不要图，有图时叠在图上，不受显示位置影响。存在外观偏好的 `grain`。
- 图片由应用校验并复制到数据目录的 `backgrounds/`；切换皮肤、恢复原外观或停用工坊都不删除背景，需要时用删除按钮清除。图片导入失败时原背景不变。
