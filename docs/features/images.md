# 截图、看图标注、生图与画廊

和图片相关的功能：全局截图（插件 `plume.screenshot`）、看图器与标注（产品自带）、agent 生图和画廊（插件 `plume.image`）。

## 屏幕截图

插件 `plume.screenshot`（从插件市场安装）：

- **全局快捷键**（默认 Alt+A）：Plume 不在前台也能截，指针所在的屏幕被定格并盖上浮层。快捷键被别的程序占用或写法无法识别时，设置页写明原因，并弹一次提示指向 设置 › 截图；同一个失败只提示一次。
- **框选**：拖一个框；不拖、直接点一下，就是指针下的那个窗口（macOS）。框好后可以拖边挪动、拖手柄调大小。
- **放大镜和取色**：框选前放大镜跟着指针，显示坐标和色值，⌘C 复制色值。
- **标注**：框好后出现工具条——画笔、箭头、矩形、文字、马赛克，可撤销。
- **完成**：图放进剪贴板（可关）；设了「截图保存位置」时同时存一份文件。
- **下载**：存到「下载截图保存到」的目录，没设就是桌面。
- **置顶**：把截图变成浮在一切之上的小窗口，可拖动，Esc 或右上角的叉关掉。
- **输入框按钮**：设置里打开后，输入框工具栏常驻一个相机按钮。
- **设置 › 截图**：快捷键、保存位置、完成后的动作、「立即截屏」。
- macOS 第一次截图会请求屏幕录制权限，在系统设置里允许后再截一次。
- 截屏调试日志写在数据目录的 `screenshot-debug.log`，超过 256KB 从头写。

## 看图器与标注

- 点对话里的图片、附件、生图结果打开看图器；看图器和对话框的遮罩采用固定的深色玻璃样式。
- 标注工具：画笔、箭头、矩形、文字、马赛克等，可撤销。
- 消息气泡里发出去的图标注完，作为「标注图.png」放回这个会话的输入框；气泡外的图标注原图。
- 复制用系统剪贴板，失败时改为下载；另存弹系统保存对话框。复制成功、剪贴板失败、导出失败、标注读图失败都有提示条。
- 应用自己的媒体图片标注时先取成字节再画，标注副本能正常导出。

## 生图

插件 `plume.image`（从插件市场安装）：

- **准备**：设置 › 模型设置里，给能出图的模型（如 `gpt-image-1`、`gemini-3.1-flash-image`）打开「生图模型」开关，可点「测试」画一张小红点图验证。有多个生图模型时在设置 › 智能体 › 会话里选默认（不选用第一个）；项目配置也可以指定默认生图模型。一个生图模型都没有时，这个工具不出现在 agent 的工具表里。对话里点名某个生图模型时 agent 会用它。
- **`image_generate` 工具**：按提示词出图，一次最多 4 张；`images` 指定要改的图——`#1` 是对话里最新的一张（人贴的附件、之前画的、截图都算），`#2` 是再往前一张，也可以给文件路径；项目外的文件先问人。最多等 5 分钟。
- **对话里的卡片**：按要求的比例先占好位置，点阵在上面流动，角上一个估计的百分比，上方一行说进行到哪一步、连接不稳时说在重试；画好后原地从模糊变清晰，上方一行是模型和尺寸。悬停有「编辑」（打开看图器标注，标好的副本进这个对话的输入框，输入框原本空着且有文字时直接发出）和「下载」；点图用看图器看；右键菜单：在所属会话的文件标签打开、添加到聊天、复制、在系统文件管理器定位、下载副本。额度用完、密钥不能用这个模型、内容被拒时画一张说明怎么处理的小卡。
- 图存在数据目录的 `session-media/`，按内容命名，同一张只存一份，不写进项目目录；要放进项目时 agent 拿结果里的路径自己复制，照常走写文件审批。缩略图（边长 800 和 128，GIF 不缩）存在 `session-media/thumbs/`。原图不随会话删除。
- 生图的 key 只在 agent 进程里使用。

## 画廊

- 侧栏「画廊」页：扫全部对话（不含子会话）里画出来的图，按天排开。
- 点开一张看大图和它的来历（从哪张改来、又改出了哪些），可以写一句要怎么改、送回它所在的对话（追加到已有草稿，不自动发送），或跳回画它的那次调用（转录滚到那里并闪一下）。
- 改图框里生成时可以停止所属会话的当前一轮，回车仍按规则排队；生成结果落盘后就地刷新，仍停在原图上时自动切到新版本，已经翻走的不抢回。
- 画廊在生图结果保存、会话摘要变化和删除后自动刷新。
- 跳回调用、送回对话在主窗口和会话独立窗口里可用；面板独立窗口里只能交给来源会话（经主窗口），跳回调用提示只能在主窗口用。
