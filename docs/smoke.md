# 冒烟各段验什么

`pnpm smoke` 怎么跑、输出在哪见 [AGENTS.md](../AGENTS.md) 的命令表和 `scripts/smoke.mjs` 的文件头；段名就是 `apps/desktop/src/main/smoke.ts` 里 `PLUME_SMOKE_ONLY === "…"` 的那些分支，`PLUME_SMOKE_ONLY=<段名>` 只跑一段。这里记各段覆盖了什么，加段、改了一段的覆盖面时同步。

主流程（段名 `main`）用真实 Electron 经界面跑一轮 agent（模型换成本地假服务），在设置 › 常规里关掉智能标题总结，装上定时任务插件（市场界面的安装、详情、筛选、停用启用、创建插件是单独的 `market` 段），覆盖输入框上方的审批卡（正文是 edit 的 diff）和面板，用内置浏览器插件在地址栏打开本机的一页、让假模型经 `browser_act` 读页面、点会弹 confirm 的按钮、点链接换页、经 `browser_screenshot` 截图，地址栏打开磁盘上的 `.html`，标签弹到独立窗口再收回，右键回复里的网址开进内置浏览器，再看内置 Git 插件的分支签和 Git 面板、看内置的子 Agent 和侧边聊天插件：子 Agent 的审批卡、子 Agent 面板、`/btw` 和排队消息经「更多」拿到侧边聊天，侧边聊天里编辑重问最后一句、把一件事交给忙着的主会话看回执条（排着时撤回回到输入框、停下后「立即执行」、随主会话停下、移除；`PLUME_SMOKE_ONLY=queue` 只跑这一段）、装下一步建议插件（不重启当场加载）看输入框灰字，看模型左边内置的上下文用量（`PLUME_SMOKE_ONLY=memory-files` 只跑点「记忆文件」在文件面板里打开会话目录外的指令文件），在回复里点开文件：带行号的文件签停在那一行、悬停出口条、右键菜单、同名的几份让人挑、文件面板里 ⌘F 的查找框，图片、PDF、音视频在文件面板里显示（`PLUME_SMOKE_ONLY=open-file` 只跑这一段），`PLUME_SMOKE_ONLY=input-menu` 只跑输入框的右键菜单（剪切、复制、粘贴、全选），`PLUME_SMOKE_ONLY=update` 只跑应用更新的界面（「检查更新…」到关于页、自动检查间隔、侧栏的更新圆点、更新对话框的进度、失败和下好后的按钮，不联网），`PLUME_SMOKE_ONLY=peers` 只跑会话互发消息（装上 plume.sessions，一个对话 `send_message` 给另一个，对方为这封信开一轮、同样 `send_message` 回，两边各有一行「来自 …」，寄出那张卡上的回执从「已送达」变成「已回复」，点那一行跳到对方），`PLUME_SMOKE_ONLY=steward` 只跑插件代管会话（构建、装上只给冒烟用的测试插件 `packages/testing/steward-probe`，先进它的页面看 `ui.usePageToolbar` 放在窗口左上角的开合按钮不压页面名、点了页面跟着开合、离开页面撤掉，再在它的面板里开一个代管会话，标题栏写着由它代管；面板转进一句话开一轮，气泡标「代管探针 转来」；假模型新建文件弹审批卡，面板「允许这一次」、桌面上的卡跟着收起，那次调用底下写「由 代管探针 代答」；再调 `ask_user`，面板交回答案；人在会话菜单「停止代管」后面板再转话被拒；改了 `packages/testing/steward-probe` 时 `PLUME_SMOKE_ONLY=changed` 只挑这一段），`PLUME_SMOKE_ONLY=spawn-session` 只跑开新会话（工作区先做成自己的仓库，假模型调 `spawn_session`（`own_initiative`，带背景），对话里画出建议卡片、收着的环境开关挂圆点，打开卡片上的工作树开关、把卡片上的思考档位改成「高」再点「开始」，开出记着来处、用这一档、第一句是「背景 + 任务」的新会话、第一轮换进自己的工作树，它跑完一轮后汇报交回原对话，那边多一行「来自关联会话」并被叫起，卡片缩成一行、点了过去；再说一件无关的事，假模型调 `spawn_session`（`offer`），输入框上方弹出要不要另开的卡，选「就在这里做」后调用处留一行记录、不开会话；最后在新会话里让它归档自己），`PLUME_SMOKE_ONLY=plan` 只跑计划模式（新对话里拨开计划模式开关再发话，edit 被拒、文件不动，交计划时输入框上方出现计划卡（等人卡，运行行说在等回答）、右栏打开计划面板；「修改…」写意见修订后模型收到没批准和意见、还在计划模式，「拒绝」让这一轮停下、开关不动；权限切到完全访问后 edit 照样被拒、命令写不出文件、申请离开沙箱被拒，计划卡照样出来、停着不被自动放行，「接受」后开关关掉、同一轮里 edit 改成功，环境卡片的「计划」一节列出批准的那份；提问卡在主流程里验）、装使用统计插件看设置 › 数据里的使用统计（`PLUME_SMOKE_ONLY=usage` 只跑一轮带工具调用的对话和使用统计的 Token 构成、耗时构成、缓存未命中），装 IM 机器人看它的设置画在插件详情里、从使用统计的详情跳到它的设置页；市场筛选「已安装」只列装上的插件，切到「技能」「连接器」两类看技能插件（带项目选择）和 MCP 插件画的那一节，在详情页停用再启用；点「创建插件」：从本地上传选的不是插件时有提示，「新建插件」开的新对话的输入框里是 `/plume-plugin`；让假模型起一条后台命令，看它结束后对话里的「后台命令完成」那一行和被叫醒的那一轮（`PLUME_SMOKE_ONLY=background-job` 只跑这一段）；`PLUME_SMOKE_ONLY=transcript-scroll` 只跑转录的滚动：假模型调六次 `ls` 合成工具组再慢慢写一段长回复，写着时（跟着底部、滚上去读两种）和写完后（读到一半、贴着底部两种）真点工具组标题展开收起，逐帧记滚动位置、被点标题的高度和视口底下的空白，写进 `transcript-scroll.json`：标题不许被推着走、位置不许往回跳、底下不许空出来；贴底收起时位置也不动、收起的那截留成底下的一块空，往上滚一屏再滚回底部它就没了；最后工具行一行一行流进点开着的卡片、人贴着底部看，量上移速度（停住后猛顶的帧、相邻帧速度差）和运行行在不在视口里；进设置 › 智能体看子智能体名单、编辑器和选脸弹层；从最后那条回复分叉、在分叉里编辑重发再撤回，写到一半按停后经「重试」原样重问，请求被放弃时不出现「重试」，让假模型新建一个文件后撤回那一问、连文件一起退回，文件之后被人改过时只能撤回对话、文件原样留着（`PLUME_SMOKE_ONLY=session-menu` 只跑会话菜单和这一段）；会话菜单「新窗口」开出独立窗口，看贴顶的标题栏、置顶、文件交给主窗口、回到主窗口和归档后窗口关掉（`PLUME_SMOKE_ONLY=session-window` 只跑这一段，完整流程里改用终端面板验证交接）；最后验证本体会话列表的项目折叠、置顶和会话窗的项目草稿、消息排队与发送（一轮收尾时自动发出的那句出现前，上一条回复已整段画出），再验证多源文件夹、主文件夹切换、悬停卡、后续会话嵌套、拖动排序持久化和项目名吸顶（`PLUME_SMOKE_ONLY=conversations` 只跑这一段）；`PLUME_SMOKE_ONLY=environment` 单独跑环境卡片（一分多钟）：假模型起一条后台本地服务、一个监视和两个检查（`schedule_wakeup`），看收着的开关上的圆点和计数、卡片里的端口签和检查、服务被认成挂着的（`stand()`）后会话不再算在等它、这一轮的交付卡、「继续」和完成通知要的 idle 照样出来、取消一项、任务面板里的服务地址，等一项到点看对话里「检查 · …」那一行，点开被叫醒那一轮新安排的检查，把界面语言换成英文、看转录里的工具行、送达那一行和卡片不重挂就当场换过来再换回，在卡片里取消它、安排它的那一行标「已停止」，最后归档会话，服务和监视跟着停掉、不再请求模型（卡片里没有「全部停止」），会话摘要是单独的 `environment-summary` 段（装上市场插件 plume.summary，说三句话后静下来一分钟，卡片里出现摘要，设置 › 智能体里有它选模型的那一行），两段并行，各一分多钟；`PLUME_SMOKE_ONLY=desktop-compat` 单独跑桌面兼容（约一分钟）：四种缩放比（经 DevTools 模拟）× 窗口大小 × 明暗主题下顶行各控件、红绿灯、带子都对在行的中线上，面板开关、标签和「添加面板」点得到；窗口变窄时面板区改成上下排，不丢面板、不重建面板内容、不改写存下的宽度和标签，拉宽回来原样；125% 下侧栏边缘落在小数像素上时标题栏和面板区的图标还在同一列设备像素上；设置页章节列表滑动时设置列一次到最终宽度、只平移；侧栏开合时逐帧量对话标题，跟着卡片走、不跳开再回来、不压到窗口按钮上，滑完撤掉动画；面板区开合时两张卡片隔 4px 一起滑、面板内容跟着卡片走、对话顶行右端的按钮不横着跳，开着的环境卡片在面板区和侧栏开合时都不重挂、不在半路换地方；`PLUME_SMOKE_ONLY=always-allow` 只跑「以后不再问」的列出和撤销（请求批准下假模型两次写同一个文件，第一次答「以后不再问」、第二次不弹卡，设置 › 常规里看到这一条、撤销，再写时重新弹卡，「全部撤销」，最后看同一页的「完全访问」开关打开前先确认、取消不动）；`PLUME_SMOKE_ONLY=steer` 只跑插话的渲染（假模型调一次 `ls`、再慢慢写一段长回复，写着时打字按回车，逐帧记排队条上那一行、气泡画出来过几个元素、转录往回挪了几帧、这一轮的过程块有几块，写进 `steer.json`：条上那一行和气泡交接的那一帧不许两样都没有、气泡不许重挂、读到插话时转录不许往回跳、这一轮不许被切成两块过程）；`PLUME_SMOKE_ONLY=hooks` 单独跑钩子插件：工作区里放一条没信任的项目钩子，看输入框上方的待审核提示、「去审核」到设置页信任它，设置 › 命令列出内置命令、同样切到这个项目、列出项目里的命令，再让它拦下一次 bash，看回复底下的「钩子」按钮和运行记录。
