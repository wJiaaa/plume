# 文档预览

内置的只读文档预览，文件面板和插件经 `ui.DocumentPreview` 共用。支持 Excel（xlsx、xlsm、xlsb、xls）、ODS、SQLite（sqlite、sqlite3、db）和 Word（docx）。CSV 继续作为文本阅读。

表格保留行号、列号、工作表切换与数字对齐；每张最多显示 2,000 行、64 列，工作簿最多 32 张表，数据库最多 64 张表或视图。Word 保留页式排版、页眉页脚、脚注、表格和图片，显示在禁止脚本和外部资源的独立文档中。

调用方先按自己的权限读取数据，再经 `ui.DocumentPreview` 交给预览器；插件不能凭路径读取调用方的目录。单文件最多 64 MiB。表格和数据库解析在独立进程中进行，5 秒超时会终止；关闭预览或插件退出会取消请求并清理临时文件。数据库使用只读副本，不执行写入。
