# Git

在 Plume 里用 Git：发送前看得到在哪个分支，agent 改了多少一直摆在眼前，看改动、提交、推送都不用离开对话去开终端。每个对话还可以在自己的工作树和分支里改，不动你的检出：几个对话同时在一个项目里干活，各改各的；做完了合回去，做坏了不碰你的工作区。

## 它做了什么

- **分支签**：输入框上方、项目旁边写着当前分支，和上游差几个提交（`↑3 ↓1`）。点开搜索、切换分支，远端分支也能直接检出；git 拒绝切换（比如没提交的改动挡着）时原样说明原因。对话在自己的工作树里（`plume/session-*` 分支）时，这里换成工作树签（见下面「工作树」），不给切分支。
- **改动计数**：输入框上方右边是还没提交的 `+增 −删`，agent 改文件时跟着变。点它打开 Git 面板。
- **Git 面板**：
  - **改动**：已暂存在上、未暂存在下，平铺或按目录看；每个文件能展开 diff、暂存、取消暂存、丢弃。图片画成图。点 diff 的行号给这一行写评论，按住拖动或按住 Shift 再点评一段；评过的行号换成序号，点它改或删。评论攒在底下一条里，「发给 Agent」把它们连同那几行 diff 一起交给这个对话：输入框是空的就直接发出去，里面有没写完的话时接在后面等你自己发。评论只在内存里，重启就没了。文件行的「预览工作区文件」打开只读文件面板，Word、表格与 SQLite 使用统一文档预览；暂存项也打开当前磁盘内容，历史和分支对比不提供这个入口。
  - **历史**：提交列表旁边画着分叉和合流，点开一个提交看它改了什么。
  - **分支**：本地和远端分支，新建、切换、删除；任意两个分支比一比差在哪。工作区里有好几个仓库或工作树时，顶上能切换看哪一个。
  - 顶上一行是拉取、提交与推送、获取三颗按钮，值得按的那一颗加重；网络卡住时再按一次就停。
- **提交与推送**：弹窗里写提交说明，留空就让默认模型按暂存的改动写一句（语言可选），可以顺手提交到一个新分支，提交后接着推送。
- **出了问题**：操作失败在窗口顶上弹提示；git 读不了这个仓库时写明原因，一键把诊断请求写进输入框。

### 工作树

- **新对话的开关**：项目是 Git 仓库时，输入框上方、分支后面有一颗「工作树」开关。开着发出第一条消息，这个对话就在新建的工作树里跑：分支 `plume/session-<编号>`，从项目当前的分支切出，目录放在工作树根目录下。项目是仓库里的一个子目录时，对话落在工作树里的同一个子目录。开关只在发第一条消息前出现，跑起来的对话挪不进副本。
- **工作树签**：有工作树的对话里，分支签换成工作树签：⑂、分支名、和基分支差几个提交（`↑2 ↓1`），同步停在冲突上时多一个琥珀色记号，目录被收走时变灰。点开是菜单：
  - **合并到基分支**：先要求提交。基分支检出在项目目录里就在那里合，有冲突立刻退回，你的检出里不留半截合并；基分支哪里都没检出时直接算出结果、挪分支，不动任何目录；检出在别的工作树里时拒绝，说出在哪。合进去以后结果下面有「归档这个对话」，点了就归档（目录照归档的规矩收走）。
  - **从基分支同步**：在工作树里合并基分支的新提交。有冲突时列出文件，可以「交给这个对话解决」（以你的身份把解决冲突的请求直接发给这个对话，在跑时排队），或者「放弃这次同步」。
  - 对话在跑时两样都不做。都不推送。还能在访达里显示工作树。
- **侧栏的 ⑂**：有工作树的对话，空闲时侧栏行首的空心圈换成 ⑂，悬停说出分支。
- **收回和检出回来**：分支比目录活得久。删除、归档对话时收走目录（分支上的提交都已在基分支里时分支一起删，否则留着），里面有没提交的改动就不收；取消归档、或者下一轮开始时目录不在，在原来的地方检出回来。检不出来时对话退回项目目录里跑。删除的确认框里说出会留下什么：没提交的文件留在哪、没合并的提交在哪个分支上。
- **建议的新会话**：模型建议另开的会话（建议新会话的卡片），卡片上的工作树开关开着时同样在自己的工作树里跑，不用输入框上的开关。
- **没建成时一直说**：要了工作树却没建成（比如 git 报错），对话在项目目录里跑，输入框上方一直有一个琥珀色提醒，点开是说明和 git 的原话。
- **设置 › 工作树**：工作树建在哪（默认 Plume 数据目录下的 `worktrees`）、建之前要不要先获取上游、要不要自动清理旧的（默认关；只清插件建的、干净的、没有对话还在用的，分支留着）；列出各项目上挂着的工作树，可以在访达里显示、删除（有没提交的改动时 git 会拒绝）。

## 用法

随应用发，不用安装。在项目里开对话，输入框上方就有分支签和改动计数。Git 面板从面板区的开始页打开，或者按 ⌘⇧R（Mac 以外是 Ctrl+Shift+R）。

分支签只在 git 项目里出现：项目目录是仓库、底下放着仓库，或者 git 读不了它（要把原因告诉你）。Git 面板在项目里就列：项目还不是仓库时，面板里可以「初始化仓库」，或「让 Agent 处理」。不属于任何项目的聊天里两样都没有。

想让一个新对话在自己的工作树里改，发第一条消息前点输入框上方的「工作树」开关。

> [!NOTE]
> 需要本机装着 git（合并到没检出的基分支要 git 2.38 以上），在 PATH 里找得到。推送、拉取用你自己的 git 配置和凭据，插件不保存任何账号信息。
>
> 工作树里的提交写进主仓库的 `.git`，它在项目目录外面：权限是「帮我批准」时，agent 在工作树里 `git commit` 会被沙箱拦下、申请提权。
