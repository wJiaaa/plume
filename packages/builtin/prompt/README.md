# 系统提示词

Plume 发给模型的系统提示词写什么。随应用发，不能停用。

## 它做了什么

- **系统提示词的各段**：身份、做事的准则、边界、环境（平台、shell、是不是 git 仓库、模型）、设置 › 个性化里的语气和全局指令、项目指令、工作目录和会话的临时目录（只为这次答案写的文件放那里，随会话删掉）。项目指令从工作目录向上找到仓库根，每层按 `PLUME.md` → `AGENTS.md` → `CLAUDE.md` → `.agent/AGENTS.md` → `.agents/AGENTS.md` 取第一份非空文件；不在仓库里时只读工作目录本身。

会话内冻结、中途变了的段作为增量消息送达、消息里的日期、插话和打断说明不在这里，由本体包在整条 `model.context` 钩子链外面（`packages/core/loop/src/prompt/`）。

## 换成自己的

它挂在 `model.context` 的外层（order -1000），其他插件的层拿到的已经是完整的一份：按段改、删、加，都在自己的层里做；要换掉身份、准则，按段上的 `category`（`identity`、`guidelines`）找。改了的段由本体冻结，中途变了的，模型在下一轮开头的增量消息里读到，系统提示词本身不变。
