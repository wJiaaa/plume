# 系统提示词

Plume 发给模型的系统提示词，以及消息里的环境信息。随应用发，不能停用。

## 它做了什么

- **系统提示词的各段**：身份、做事的准则、边界、环境（平台、shell、是不是 git 仓库、模型）、设置 › 个性化里的语气和全局指令、项目指令、工作目录和会话的临时目录（只为这次答案写的文件放那里，随会话删掉）。项目指令从工作目录向上找到仓库根，每层按 `PLUME.md` → `AGENTS.md` → `CLAUDE.md` → `.agent/AGENTS.md` → `.agents/AGENTS.md` 取第一份非空文件；不在仓库里时只读工作目录本身。
- **会话内冻结**：系统提示词在会话的第一次请求时定下，之后原样复用，服务商的前缀缓存才接得上。项目指令、技能、子智能体名单这些中途变了的段，作为一条增量消息接在下一轮的开头，模型从那里读到新的；压缩以后（或撤回到第一条消息）按磁盘现状重新定一份。冻结的那份存在插件数据目录里，重开应用还是同一份。
- **日期**：每个新日期的第一条消息后面接一句今天是几号。不放进系统提示词，服务商的前缀缓存才命中得住。
- **插话和打断说明**：插进正在跑的一轮、或打断了一轮的那条消息，发给模型时前后各加一句，说清它是在工作中途发来的。

## 换成自己的

它挂在 `model.context` 的最外层（order -1000），其他插件的层拿到的已经是完整的一份：按段名改、删、加段，或者把 `sections` 整个换掉，都在自己的层里做。里层交回的段会和冻结的那份比对：自己的段中途变了，模型在下一轮开头的增量消息里读到，系统提示词本身不变。
