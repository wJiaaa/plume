# 开新会话

模型在对话里遇到一件该单独做的事——你刚提的新任务、你要求拆出去的一块、它自己顺手发现的问题——就另开一个会话去做。开出来的会话挂在这个对话下面，每结束一轮都把结果交回来。

## 它做了什么

- **`spawn_session`**，按谁的主意分三种：
  - **问你（offer）**：你这句话提了一件和手上的事无关的新任务。输入框上方弹一张卡「要另开一个会话吗？」，模型等你选：「开新会话」就另开，它补一段简报、用一行话告诉你开在哪；「就在这里做」就在当前对话里做；「以后不再问」之后都在当前对话里做、不再弹卡。拿不准是不是新任务时，模型当成接着做，不问。
  - **你要求的（user_asked）**：你明说要单开、并行或放到后台，当场开出来。
  - **它自己发现的（own_initiative）**：没人用的代码、过时的文档、缺的测试、顺手发现的安全问题。只在对话里放一张建议卡，什么都不跑，你点「开始」（或者跟它说「开第二个」）才开。一轮最多三张，七天后过期。
- **简报**：新会话的第一句是「背景 + 任务」：已经定下的目标、决定和约束，这一块在整件事里的位置，再是要做什么、什么算做完。也可以带着这个对话的全部记录开（fork）。每个开出来的会话有个短名（比如 `cli-cleanup`），会话之间靠它称呼。
- **建议卡**：标题、一两句理由和右上角的收起；下面一排左边是工作树开关（只在这个对话属于 Git 项目时出现），右边是模型、思考档位和「开始」。开始以后缩成一行「新会话 · 标题」，那个会话在跑时扫光，没跑完时标红，点了过去。收起只记在这台机器上；模型撤回的（`dismiss_task`）、过期的也缩成一行。
- **工作树**：打开时，新会话在它自己的 Git 工作树和分支里跑，不动项目的检出，几个会话同时改同一个仓库也不互相踩；之后在它的工作树签上合回去（见 Git）。
- **`hand_off_to_session`（移交）**：一件事做到一半，你发来一句无关的新话，模型把手上的事连同整段对话和剩下的计划移交给一个新会话继续，这个对话转去回答你。
- **每轮汇报**：开出来的会话每结束一轮，把收尾那段回复的前 400 字交回这个对话，对话里多一行「来自关联会话 · 标题」。第一轮、以及这个对话发消息给它引起的那一轮做完，会叫起这个对话接着处理；它在等子 Agent、后台命令的结果时先不交，等回来以后那一轮再交。这个对话正闲着、它开出的会话都停下了才叫起，几份合成一次。
- **被开出来的会话**：系统提示词里多一节，说明它是从哪个会话开出来的、只做交代的那件事、把结果放在回复开头（汇报只取开头）、卡住时只问一句短问题。
- **`archive_session`**：你说「做完就归档」这类话时，模型把最后的回复写完、再调它，这个对话就在这一轮做完后归档，界面离开它。模型不会自己想归档就归档。
- **环境卡片**：「建议的新会话」一节列出还没决定的建议（点一条滚回对话里那张卡片）和开始了的会话在做什么。卡片收着时，还有没决定的建议，标题栏的环境开关上挂一个圆点。

## 边界

- 你在开出来的会话里自己说话引起的那一轮、被你停下的、出错的，汇报照样交，但不叫起这个对话，留到它下一轮开头读；被你按停的那一轮不交。
- 别的会话寄来的消息引起的那一轮，模型只能提建议，不能当场开、也不问你。
- 连着被汇报和消息叫起十轮、中间你一句话都没说，之后的汇报留到你下次开口。
- 「以后不再问」只记在这台机器上；想再被问，在设置 › 常规里打开「另开会话前先问我」。
- 子 Agent 和侧边聊天里用不了：它们不是侧栏里的对话。
- 归档不当场做：那会把正在说话的这一轮砍掉，所以这一轮停在这一下、收场之后再归档。这一轮要是被你停下或出了错，就不归档。想找回来：设置 › 已归档的聊天。

## 用法

随应用发，不用设置。也可以直接说：

> 把这三块拆成三个会话分头做，我在这里看结果。

> 修好就把这个对话归档。
