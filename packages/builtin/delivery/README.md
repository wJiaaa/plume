# 文件交付

随应用提供的文件交付卡片，汇总每轮实际留下的文件净变更。展开卡片可以查看差异，撤销单个文件或整轮改动。

记录以真实用户消息为轮次边界，继续、补充上下文等系统消息不另切一轮。只汇总本体记在工具结果上的改动（`ToolResultMessage.changes` 的快照标识和警告），不认是哪个工具交的，也不从界面接收文件原文；净变化计算和撤销前的安全校验由本体的 `ctx.changes` 负责，快照不可用时把警告留在交付数据里，不把记录缺失当作没有改动。

卡片默认列三个文件，展开时保留高度过渡；文件行支持悬停预览、键盘聚焦预览和右键菜单。“审核”打开本轮差异，不调用模型。撤销先确认，再由服务端复查文件；已有后续修改、修改链不连续、超出项目边界和命令观测的变更不能自动撤销。

撤回或编辑重发一条消息时连文件一起退是本体做的（`@plume/agent` 的 `run-files.ts`），读的是同一份 `ToolResultMessage.changes`，不经这个插件。
