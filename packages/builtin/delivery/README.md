# 文件交付

随应用提供的文件交付卡片，汇总每轮实际留下的文件净变更。展开卡片可以查看差异，撤销单个文件或整轮改动。

记录以真实用户消息为轮次边界，继续、补充上下文等系统消息不另切一轮。只汇总工具结果中的快照标识，不从界面接收文件原文；净变化计算和撤销前的安全校验由 `file.changes` 服务负责，快照不可用时把警告留在交付数据里，撤回时据此判断有改动没记全，不把记录缺失当作没有改动。

卡片默认列三个文件，展开时保留高度过渡；文件行支持悬停预览、键盘聚焦预览和右键菜单。“审核”打开本轮差异，不调用模型。撤销先确认，再由服务端复查文件；已有后续修改、修改链不连续、超出项目边界和命令观测的变更不能自动撤销。

撤回或编辑重发一条消息时，插件在钩子 `session.rewind` 里答截掉的那几轮改过哪些文件、各自能不能安全退回；人选了连文件一起退，就在对话截断之前把它们退回到那条消息之前的样子，新建的文件删掉。全有或全无：有改动没记全，或有一个文件来自命令、中途或之后被改过、不在项目内，就一个文件都不写，对话也不截，原因报给人。
