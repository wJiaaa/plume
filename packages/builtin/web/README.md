# 网页搜索

让 agent 能上网查资料：搜索网页，再把搜到的网址读成文字。随应用发，不配置也能搜（效果有限），填一个 API key 效果好得多。

## 它做了什么

- **工具 `web_search`**：按一句查询搜网页，交给 agent 最多 8 条结果（标题、网址、摘要，有的服务还附一段总结）。30 秒没有响应就算超时。
- **工具 `web_fetch`**：把一个 http(s) 网址读成文字。网页转成保留标题、列表、表格、代码块的纯文字；也能读纯文本、JSON、XML。单个响应最多 2 MB，正文太长时截断并标出来；最多跟 3 次同一站点内的跳转，跳到别的站点时不跟，让 agent 自己决定要不要去读那个地址。
- **设置页「网页搜索」**：选用哪一家搜索服务，填各家的 API key。

两个工具都只读，不会弹审批卡；对话里显示成通用的工具卡片。搜到、读到的文字按不可信内容交给 agent，它不会把网页里的话当成给它的指令。

## 用法

1. 打开设置 →「网页搜索」，在「用哪一个」里点选一家；再点一次已选的那家就取消，回到自动挑选。
2. 选的是要 key 的服务，就在下面「API key」里点「申请」去对方网站拿一把，贴进输入框。key 停手后自动保存，存过的框里显示「已保存」，填新的会替换，点「清除」删掉。

没选的时候按这个顺序自动挑：只有一家能用就用它；填了 key 的只有一家就用它；什么 key 都没填就用 DuckDuckGo 速答；填了好几把 key 又没选，搜索会报错，提醒你去选一家。

设置改了下一次搜索就生效，不用重启。设置和 key 存在本机这个插件的数据目录里（`search.json`，只有你自己的账户能读），不经过界面。key 经 Plume 本体的密钥加密（`ctx.secrets`）加密后写进去，文件里是 `plume-sealed:v1:` 开头的一段；加密用的钥匙丢了，key 会显示成没填，重新填一遍就行。

## 各家的区别

| 服务 | 要 key | 适合 |
| --- | --- | --- |
| Tavily | 要，每月 1000 次免费 | 为 agent 设计，结果附一段总结，通常最省事 |
| DeepSeek | 要，按次计费（每 1000 次 5 元） | 中文结果好，认识 `site:`、`lang:`、`after:` 这类语法 |
| Brave Search | 要，每月 2000 次免费 | 独立索引，免费额度最大 |
| Exa | 要，有免费额度 | 语义检索，找概念和相似内容比找关键词强 |
| DuckDuckGo 速答 | 不要 | 官方接口、稳定，但只有百科式答案，基本只对英文词条有效 |
| DuckDuckGo | 不要 | 直接读它的无脚本网页，常被限流，不适合当主力 |

搜索会把你的问题发给选中的服务商。
