# 会话环境

标题栏上的「环境」开关，和点开后跟着会话的那张环境卡片：一眼看到这个会话周边的事，每一行都是入口。

## 它做了什么

- **卡片自己的三节**：打开方式（用哪个应用打开这个会话的目录）、子会话（按建它的插件分节，节名是那个插件的显示名，比如「子智能体」「侧边聊天」；点一行在面板里看那个子会话，多于 5 个时「还有 N 项」打开完整列表）、引用（对话里附过的文件和图片，点了打开）。
- **别的插件加的节**：插件经 `ui.environmentSection` 往卡片里放一节，按 order 排进这三节之间。随应用提供的有：后台任务、定时唤醒、压缩记录（运行诊断），批准过的计划（计划模式），建议的新会话（建议新会话）；市场插件可以加自己的（拉取请求、会话摘要）。卡片不认是谁加的，某个插件停用或换掉，只是少了它那一节。
- **显示哪些内容**：卡片右上角选显示哪几节，选择只记在这台机器上；空的节不占位。
- **收着时的圆点**：卡片收着时，各节有事要提醒（等你决定的建议新会话，会自己叫醒这个会话的定时唤醒、监视）就在开关上挂一个圆点，那几句话接在开关的说明后面。藏起来的节不提醒。
- **放在哪**：对话那一列够宽时停靠在右边一列，转录和输入框让开；不够时浮在转录右上角，从不放到输入框上方。

## 用法

随应用提供，不能停用。点标题栏的「环境」开关打开、收起。
