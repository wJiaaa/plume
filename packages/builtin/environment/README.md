# 会话环境

标题栏上的「环境」开关，和点开后跟着会话的那张环境卡片：一眼看到这个会话周边的事，每一行都是入口。

## 它做了什么

- **页头与版本控制**：页头放系统打开方式和项目脚本；紧接独立的版本控制块（分支切换、Git 快捷操作），不画组标题，空时折叠。
- **按节分开展示**：后台任务、定时任务、子智能体、计划、关联会话、拉取请求、引用各自独立成组，标题默认带数量计数（可按节关闭，子智能体与关联会话不显示数量）；压缩记录放在卡片页脚。没有内容的组不占位、不留分隔线。
- **统一的行**：各节里的每一行都是图标（子智能体显示对应智能体头像）、人话标题、右侧机器事实；运行中只在图标上挂绿点，倒计时用行底细线。待决定的新会话建议不显示，只有真的开出会话后才出现在「关联会话」里。
- **显示哪些内容**：卡片没有设置按钮，在卡片上右键选择。选择只记在这台机器上；空内容不占位，各项都藏起来时卡片里留一行「选择显示的内容」。
- **收着时的圆点**：只有会自己叫醒会话的监视、检查和定时任务提醒；普通长跑服务和未开始的会话建议不点亮。藏起来的内容不提醒。
- **外观与位置**：实底浮层总是浮在转录右上角，转录和输入框不让位，从不放到输入框上方。

## 用法

随应用提供，不能停用。点标题栏的「环境」开关打开、收起；开合时卡片从右上角轻轻放大淡入、缩回淡出。
