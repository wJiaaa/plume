# 智能标题

给会话起一个一眼能认出来的标题：把第一条消息概括成一句话，而不是截下它的开头。

## 它做了什么

- **什么时候起**：只在一个会话发出第一条消息时起一次。消息去掉多余的空白后不超过 12 个字的，开头本身就够当标题，不再总结；之后的消息、侧边聊天和子 Agent 这类子会话都不处理。
- **怎么起**：在后台用设置 › 智能体 › 会话里「智能标题模型」选的模型（不选就是这个会话自己的模型）写一句 6 到 18 个字的标题，语言和你的消息一致；问题会写成「问的是什么事」，不回答它。不拖慢这一轮的回复，写好了侧栏和标题栏上的那行字就换掉。
- **起不出来时**：没配模型、15 秒内没回来、出错，或者模型回的不像标题（太长），都保留默认取的消息开头。

## 用法

随应用发，缺省开着。想换一个便宜点的模型起标题，在设置 › 智能体 › 会话里选「智能标题模型」；选的模型后来没了，就不再起标题、保留默认取的开头，换一个或改回跟随即可。

> [!NOTE]
> 每个会话起标题会多调一次模型（发过去的是第一条消息，最多前 4000 个字），用量记在这个会话名下。
> 不想要了，在设置 › 常规里关掉「智能标题总结」，标题回到取第一条消息的开头。
