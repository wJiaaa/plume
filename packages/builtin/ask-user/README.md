# 向你提问

随应用提供的 `ask_user` 工具：Agent 遇到自己答不了的问题（要你澄清意图、在几条路里拿主意）时停下来问你，你答了它再接着做。

问题压在输入框正上方，和审批卡在同一个位置。选项可以带一行说明和「推荐」标记；可以单选或多选，可以在「其他」一行里自己写，也可以跳过。跳过不是同意：Agent 事先指定了默认项时采用默认项（卡上写着「跳过将采用：…」），没指定就只接着做不依赖这个答案的事。键盘上 1–9 选第几项，0 去「其他」那一行写，Esc 跳过，回车确认。

这是问你的决定，不是要权限：完全访问也不会替你回答。没人回答时等 30 分钟，卡上有倒计时；到时按没有答案收场，Agent 会在回复里说明它问过、没等到回答、改做了什么。你的回答在插件里再核一遍，对不上问题的（不在选项里又不许自填、单选交了多个）不收。
