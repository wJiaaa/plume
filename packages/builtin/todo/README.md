# 待办清单

多步的任务，让 agent 先列一张清单，做完一项勾一项。你随时能看到它打算做什么、做到了哪一步、还剩多少。

## 它做了什么

- **工具 `todo_write`**：三步以上的活，agent 每次把完整的清单发过来，整张替换；同一时刻只有一项在做。清单记在会话里，翻回去也看得到。
- **清单卡片**：一直跟着对话。对话那一列够宽时浮在右上角，窄了就放在输入框正上方。标题行写的是现在在做哪一步、勾到第几项；点它收起成一行，再点展开。在做的那一步按这一轮的样子画：在跑、你按了停、请求失败，还是这一轮收了尾它还没勾上。标题行右边、指针在那一步上停一秒，都有它的动作：在跑时暂停，失败了重试这一步，停下了继续。全部勾完卡片自己收走。
- **清单跟着事走**：agent 回答完了清单还有一项「正在做」，替你问它一次；它只是补勾清单的话，这一轮就此结束，对话里不多一行。单独更新一次清单、或者 20 步没更新清单，也会提醒它一句。
- **对话里**：每次更新清单并进那一段活，说成一行「更新清单 2/5 · 在做的那一项」，不另占一张卡片。
