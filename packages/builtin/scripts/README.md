# 项目脚本（plume.scripts）

在会话环境卡片和设置页管理项目级与全局默认脚本，一键在终端中运行常用命令（启动开发服务、测试、检查、构建等）。

## 功能

- **环境卡片快捷入口**：环境卡片顶部整行分割按钮一键运行主脚本（按项目记住上次运行的脚本），下拉可切换、编辑、添加或从仓库的 `.plume/scripts.json` 导入脚本。
- **工作树初始化脚本**：可指定一条脚本在新建对话工作树后自动运行，支持后台异步或同步等待完成再启动会话。
- **归档 / 删除自动停止**：勾选「归档会话时停止」的脚本在会话归档或删除时自动关闭对应终端。
- **自动打开预览**：填写预览地址并启用自动打开后，启动脚本时自动打开对应链接。
- **设置 › 项目脚本**：管理全局默认脚本和各项目独立配置，支持一键重置为全局默认。
