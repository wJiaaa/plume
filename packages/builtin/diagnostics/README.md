# 运行诊断

随应用提供的内置插件，集中查看当前会话的后台任务、运行记录、调用轨迹和环境。

- 面板开始页选择「任务」，或按 ⌘J：查看计划、后台任务和工具运行记录，按状态、命令、参数或输出筛选。已结束的后台任务保留到应用退出；展开可读最新日志，停止与强制结束只作用于选中的任务。
- 选择「调用轨迹」、按 ⌘L，或在会话菜单点「查看调用轨迹」：按轮次查看模型请求、系统提示词、思考、回复、工具、审批与重试。可按来源、状态、文字和时间范围筛选，查看关联记录、输入输出与原始信息，并导出 JSON 或 Markdown。
- 点击标题栏的「环境」：查看打开方式、还在运行的后台任务、子 Agent、侧边聊天、压缩记录和引用；别的插件也在这里加自己的分区（批准过的计划、建议的新会话、拉取请求、会话摘要）。右上角选择显示的分区，空分区不占位。
- 点击对话中的后台任务完成行，直接定位任务输出；运行详情可以跳到轨迹或原工具卡片。

诊断观察保存在插件私有目录的 `diagnostics.db`，不保存供应商配置、请求头或密钥，图片像素与不透明供应商签名不重复保存。撤回时截断对应观察，删除会话时清除它的观察。启用前的历史通过原会话还原消息与工具记录，不补造当时未保存的请求上下文和耗时。

日志预览最多读取开头 2 MiB，超过时文件预览会提示；完整日志仍在原路径，可经标题栏用编辑器打开。后台输出只读尾部 256 KiB，不影响模型的未读输出与完成送达。
